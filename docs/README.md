# はじめに

nagiyu-platform は、AWS 上で動く個人開発のサービス群と、それらが共有するライブラリ・インフラをまとめたモノレポです。このサイトでは、各サービスが何を満たすべきか、今どう動くか、守る規約は何かを読めます。

サイトは https://nagiyu.github.io/nagiyu-platform/ で公開しています。develop に取り込まれた内容が反映されます。

## 読み方

左のメニューは 2 つの章に分かれています。

| 章 | 中身 |
|---|---|
| サービス | サービスごとの要件と仕様 |
| 共通基盤 | サービスをまたいで使う共通ライブラリ・CI・インフラの仕様と、開発の規約 |

### サービス

サービスの中のページは、知りたいことで読み分けます。

| 知りたいこと | 読むところ |
|---|---|
| 何を満たすべきか、何をやらないと決めたか | 要件 (目的、ドメインモデル、ユースケース、機能要件、非機能要件) |
| 今どう動くか、何がどこにあるか | 仕様 (画面、API、バッチ、処理の流れ、用語、リソース、データ、デプロイ先) |

仕様はコードの写しで、コードが変わると CI が作り直しを求めます。要件にはコードからはわからない理由と、やらないと決めたことを書いています。

### 共通基盤

| 知りたいこと | 読むところ |
|---|---|
| 共通ライブラリ・CI・共通インフラの今の挙動 | 仕様 |
| 開発で守る規則と、その理由 | 規約 |

## ドキュメントの方針

文書の分類・配置・書き方は [docs の書き方](platform/rules/docs.md) にまとめています。サイドバーは `docs/layout.json` の配置とディレクトリから自動で作るため、このページには文書の一覧を載せません。

# 個人の ToDo を管理する

利用者が、自分だけが見られる個人リストで、ToDo を追加し、完了にし、直し、消す。

## 前提

- Share Together にログインしている ([サインインと利用者の登録](../functional/sign-in.md))

## 流れ

1. 利用者が[リスト画面](../../specs/screen/lists.md)を開く。デフォルトの個人リストが開く
2. 必要なら、個人リストを作る、名前を変える、削除する ([個人リスト](../functional/personal-list.md))
3. ToDo のタイトルを入れて追加する
4. 終えた ToDo を完了にする。完了を取り消して未完了に戻すこともできる
5. ToDo のタイトルを直す、不要な ToDo を削除する

## 結果

- 個人リストの ToDo が、利用者の操作どおりに残っている。ほかの利用者には見えない

## 例外

- 個人リストが上限の 100 件に達していると、新しい個人リストは作れない
- デフォルトの個人リストは削除できない

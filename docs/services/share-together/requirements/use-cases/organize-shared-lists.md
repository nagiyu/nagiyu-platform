# 共有リストを整理する

グループの承認済みメンバーが、共有リストを作り、名前を変え、不要になったものを削除して、グループのリストを整える。

## 前提

- Share Together にログインしている
- 利用者が、グループの承認済みメンバーである

## 流れ

1. 利用者が[リスト画面](../../specs/screen/lists.md)で表示範囲を「共有」にし、グループを選ぶ。共有リストは[グループ画面](../../specs/screen/groups.md)からも作れる
2. 共有リストを作る、または、既存の共有リストの名前を変える、削除する ([共有リスト](../functional/shared-list.md))
3. サービスが操作を反映し、成功か失敗を利用者に知らせる。リストの一覧の表示名が更新される、または一覧から消える

## 結果

- グループの共有リストが、操作どおりに整っている。削除したリストの ToDo も消える
- 削除したリストが開いていたものなら、ほかのリストがあればそこへ移る

## 例外

- 承認済みのメンバーでない人が API を直接呼んでも、拒否される ([アクセス制御](../non-functional/access-control.md))

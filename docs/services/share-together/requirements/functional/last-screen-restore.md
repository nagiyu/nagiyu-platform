# 前回の画面の復元

PWA として開き直したときに、前回に開いていた画面から再開できるようにする。

## 要件

- 利用者が、PWA を閉じて開き直したとき、前回に開いていた画面から再開できる。リスト画面では、選んでいたリストも復元する
- 前回の画面は、端末ごとに保存する。ほかの端末やブラウザには引き継がない
- 前回の画面が無い、またはトップ画面だったときは、トップ画面のまま始める
- 復元は、そのセッションの最初の表示のときだけ行う。トップ画面へ戻る操作では移らない

今の挙動は[起動時の流れ](../../specs/flow/session-start.md)にある。

## やらないこと

- **端末をまたぐ復元**: 前回の画面はブラウザの保存領域だけに持ち、サーバーには保存しない。端末をまたぐ同期は、このサービスの要件にない

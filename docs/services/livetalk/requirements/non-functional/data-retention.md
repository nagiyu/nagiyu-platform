# データの保持

利用者のデータを、どれだけ残し、いつ消すか。値は定数で決まり、保存先の詳しい表は[メインテーブル](../../specs/data/main-table.md)にある。

## 要求水準

| データ | 保持 |
|---|---|
| 会話履歴 | 90 日で自動削除する |
| Web 取得の生データ (WebRaw) | 90 日で自動削除する |
| 通知の記録 | 30 日で自動削除する |
| 勉強の依頼 | 30 日で自動削除する |
| 鮮度確認の依頼 | 7 日で自動削除する |
| 勉強の 1 日の回数 | その日が終わった翌日に自動削除する |
| セーフティの記録 | 検出から 3 年で自動削除する。退会しても消さず、匿名にして期限を引き継ぐ |
| 話題 (Topic)・SELF fact・WEB fact・ノート・ノートを作らない記録・探索の記録 | 期限を持たない。SELF fact は利用者が消せる。WEB fact は件数に上限を置き、古いものから消える |
| 親密度・同意・生活サイクル | 在籍中は期限を持たない |

- 退会すると、セーフティの記録を除くすべてを、すぐに消す ([退会とデータの削除](../functional/account-deletion.md))
- 自動削除は、期限を過ぎてもすぐには消えない。保存先の仕組みにより、物理的な削除は最大 48 時間遅れうる
- 鮮度確認の依頼を 7 日で消すのは、枠や予算で後回しになり続けた依頼が溜まらないようにするため。消えても、その話題が次に使われたときに、また依頼される
- セーフティの記録を残す理由は[セーフティ](../functional/safety.md)にある

## やらないこと

なし

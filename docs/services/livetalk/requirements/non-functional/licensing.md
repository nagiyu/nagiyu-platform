# ライセンス

キャラクターと音声の素材のライセンスを守る。対象は、Live2D のモデル、VOICEVOX、AI で生成した絵と音声である。

## 要求水準

- **Live2D**: 桃瀬ひよりは、Live2D の公式サンプルである。Live2D Free Material License に従い、年商 1,000 万円未満の間は商用で使える。年商が 1,000 万円を超える前、または中・大規模事業者として扱われる前に、Live2D と別途契約する
- **桃瀬ひよりの画像**: 桃瀬ひよりの個別の利用規約に従い、画像を改変しない。改変すると規約に違反するおそれがあるため
- **VOICEVOX**: 冥鳴ひまりのクレジット (「VOICEVOX:冥鳴ひまり」) を、画面のフッターに常時表示する。VOICEVOX のエンジンは、HTTP API 越しに使い、組み込まない (エンジンの LGPL に影響しない)
- **Live2D のクレジット**: 桃瀬ひよりのクレジット (「Live2D キャラクター: 桃瀬ひより ©2010 Live2D Inc.」) を、フッターに常時表示する
- **AI で生成した素材**: 早瀬アゲハの絵は OpenAI の画像生成による AI 生成、音声は OpenAI の音声生成モデルによる AI 生成音声 (人間の音声ではない) であることを、フッターに示す
    - 音声は、OpenAI の利用規約上、AI 生成音声であることの明示が必須である
    - 絵は、規約上の必須表記ではない。AI 生成物を人間が作ったものと誤認させないため、音声の開示にそろえて示す
- クレジットは、選んでいるキャラクターに連動して切り替わる ([キャラクター](../functional/characters.md))
- 画面のフッターは、全画面に共通である ([ホーム画面](../../specs/screen/home.md))

## やらないこと

- **利用者がクレジットを消すこと**: クレジットの常時の表示は、利用許諾の条件であるため、非表示にする設定を持たない

# 法的対応

法令への対応として、サービスが満たすこと。

## 要求水準

- **医療目的でないこと**: 医療・心理カウンセリング・診断を目的としないことを、初回の同意のダイアログと、利用規約で明示する。精神的な辛さを感じているときは専門機関への相談を勧める ([同意](../functional/consent.md))
- **セーフティの限界**: セーフティは自動で動くもので、緊急時の対応を保証しない旨を、利用規約に示す ([利用規約](../../specs/screen/terms.md))
- **18 歳以上**: 利用の前に、18 歳以上であることを自己申告で求める ([同意](../functional/consent.md))
- **規約と同意**: 利用規約・プライバシーポリシーを示し、同意を取る。版が上がったときは、取り直す ([同意](../functional/consent.md))
- **退会と開示**: 利用者が自分のデータを消せる導線を持つ。開示請求には、人手で応じる ([退会とデータの削除](../functional/account-deletion.md))
- **国内法**: 国内の法令に準拠する

## やらないこと

なし

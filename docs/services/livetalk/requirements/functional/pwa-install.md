# ホーム画面への追加

ブラウザで開いている利用者に、キャラクターの言葉で、ホーム画面への追加を案内する。追加すると、アプリのように開ける。ユースケースは[ホーム画面に追加する](../use-cases/install-to-home-screen.md)。

## 要件

- 同意のあと、ブラウザで開いているときは、ホーム画面への追加を案内する。案内の文は、キャラクターの言葉で書く ([ホーム画面](../../specs/screen/home.md)、[PWA](../../specs/term/pwa.md))
    - iOS では、共有ボタンから「ホーム画面に追加」を選ぶ手順を示す
    - それ以外では、「ホーム画面に追加する」のボタンで追加を始められる
- ホーム画面に追加した状態で、Push に対応し、通知が未許可のときは、通知を許可する案内を出す ([通知を有効にする](../use-cases/enable-notifications.md))
- 案内は「あとでね」で閉じられる。閉じると 3 日は出さない
- 追加を、会話の条件にしない。ブラウザのままでも会話できる

## やらないこと

なし

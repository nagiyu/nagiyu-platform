# ギフトノート

キャラクターが、利用者が気にしている話題について調べたことを、なぜ調べたのかとともに、手紙 (ノート) にして贈る。利用者は、贈られたノートを読める。ユースケースは[ノートを読む](../use-cases/read-notes.md)。

## 要件

- 利用者が会話で何度か触れた話題 (care が閾値以上) で、調べた内容 (WEB fact) があるものを、ノートの候補にする ([care](../../specs/term/care.md)、[集約バッチ](../../specs/batch/consolidate-conversations.md))
- ノートは、利用者が言ったこと (なぜ調べたか) を根拠に、調べた内容を贈る手紙にする。調べたことだけを並べた報告書にしない。同じ話題に、利用者の事実と調べた内容が同居しているので、根拠付きで語れる
- ノートは、1 つの話題につき 1 つまで作る。乱発しないよう、1 回の実行で作る数にも上限を置く
- 手紙の文面は、贈った時点のまま変わらない。調べた内容と出典は、開くたびに話題の最新を読む ([ノート](../../specs/term/note.md))。贈った瞬間は 1 度きりの出来事として残し、中身は生きた話題を参照する
- 利用者は、ノートを一覧と詳細で読める ([ノート一覧画面](../../specs/screen/notes.md)、[ノート詳細画面](../../specs/screen/note-detail.md))
- 直近に贈ったノートを会話に渡し、利用者の感想に、キャラクターが反応できる
- ノートにしないと判断した話題は、新しい WEB fact が増えるまで評価し直さない。ノートは、利用者の事実と WEB fact の合成で、評価の入力のうち変わりうるのが WEB fact であり、入力が変わらないまま LLM を呼ぶ無駄を避けるため。利用者の事実だけが増えたときは、評価し直さない

## やらないこと

- **会話で頼まれた調べものをノートにすること**: 利用者が会話で頼んだ調べものの結果は、会話で返す。ノートは、キャラクターが自分から贈るギフト専用にする
- **ノートの編集・削除**: 読むだけの機能にする

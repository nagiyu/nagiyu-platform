# 親密度

利用者とキャラクターの接触量を、キャラクターごとに累積して持つ。上がるだけで、下がらない。

## 要件

- 親密度は、利用者がキャラクターと新しい日に話したときに上がる。キャラクターごとに持つ ([親密度](../../specs/term/affection.md))
- 長く話さなくても、下げない。長く話さなかったことは、通知の文面の口調で表す ([Push 通知](push-notification.md))
- 退会すると消える ([退会とデータの削除](account-deletion.md))

## やらないこと

- **親密度を下げること**: 戻ってきた利用者を責めるダークパターンを避けるため ([親密度](../../specs/term/affection.md))

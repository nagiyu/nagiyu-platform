# キャラクターの見せ方

キャラクターを画面の中で、生きているように見せる。描き方は、キャラクターごとに Live2D か一枚絵から決まり、音声に合わせて口が動く。

## 要件

- キャラクターは、ブラウザの中で描く。サーバーは文字と音声だけを返す ([キャラクター](../../specs/term/character.md))
- 描き方は、キャラクターごとに決まる
    - **Live2D**: 待機の動きと瞬きを持つ。音声に合わせて口が動き、就寝中は目が半開きになる ([生活サイクル](lifecycle.md))
    - **一枚絵**: 一枚絵のパーツを重ね合わせ、瞬きをし、音声の大きさに合わせて口を開け閉めする。開いた状態と閉じた状態を排他で切り替え、中間のフェードはしない
- 音声はキャラクターごとに決まる
- 音声は、利用者の最初の操作で再生の準備をする ([ホーム画面](../../specs/screen/home.md))
- 状態 (待機中、考え中、話している) を文字でも示す
- キャラクターのクレジットを、常に表示する ([ライセンス](../non-functional/licensing.md))

## やらないこと

- **サーバー側での描画**: サーバーで描いた動画を返さない。費用・遅延・帯域の面で実用的でないため
- **メインのキャラクターを一枚絵に置き換えること**: メインのキャラクター (桃瀬ひより) は Live2D を保つ。一枚絵は表現力が Live2D に劣り、「生きている感じ」というリブトークの核が下がるため。一枚絵は、Live2D を持たないキャラクターのための方式にとどめる

詳しい理由は[キャラクター](../../specs/term/character.md)にある。

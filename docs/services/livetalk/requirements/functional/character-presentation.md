# キャラクターの見せ方

キャラクターを画面の中で、生きているように見せる。描き方は、キャラクターごとに Live2D か一枚絵から決まり、音声に合わせて口が動く。

## 要件

- キャラクターは、ブラウザの中で描く。サーバーは文字と音声だけを返す
- 描き方は、キャラクターごとに決まる
    - **Live2D**: 待機の動きと瞬きを持つ。音声に合わせて口が動き、就寝中は目が半開きになる ([生活サイクル](lifecycle.md))
    - **一枚絵**: 一枚絵のパーツ (ベース、開いた目と閉じた目、開いた口と閉じた口) を重ね合わせる。瞬きをし、音声の大きさに合わせて口を開け閉めする。音声の解析は Live2D と同じ手段を使い、描き方が増えても発話の演出をそろえる
- 一枚絵の瞬きと口は、開いた状態と閉じた状態を排他で切り替える。中間のフェードはしない。連続のフェードより動きが明確で、重ねた下のパーツが透ける不具合も避けられるため
- 音声はキャラクターごとに決まり、文ごとに合成して順に再生する ([キャラクター](../../specs/term/character.md))
- 音声は、利用者の最初の操作で再生の準備をする。ブラウザが操作なしの自動再生を制限するため ([ホーム画面](../../specs/screen/home.md))
- 状態 (待機中、考え中、話している) を文字でも示す
- キャラクターのクレジットを、常に表示する ([ライセンス](../non-functional/licensing.md))

## やらないこと

- **サーバー側での描画**: サーバーで描いた動画を返す方式は採らない。コスト・レイテンシ・帯域の面で実用的でないため
- **メインのキャラクターを一枚絵に置き換えること**: メインのキャラクター (桃瀬ひより) は Live2D を保つ。一枚絵は、母音ごとの口の形や連続的な表情の変化ができず、「生きている感じ」というリブトークの核が下がるため。一枚絵は、Live2D を持たないキャラクターのための方式にとどめる ([キャラクター](characters.md))

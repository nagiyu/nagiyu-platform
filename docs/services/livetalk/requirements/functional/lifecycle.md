# 生活サイクル

キャラクターに、就寝と起床の時刻がある。寝ている時間帯の応答は寝ぼけた口調になり、利用者の生活に合わせて時刻が少しずつ寄る。ユースケースは[キャラクターの生活サイクルを体験する](../use-cases/experience-lifecycle.md)。

## 要件

- キャラクターは、利用者 × キャラクターごとに、就寝時刻と起床時刻を持つ。時刻には既定がある ([生活サイクル](../../specs/term/lifecycle.md))
- 就寝中に話しかけられると、短く、ぼんやりした寝ぼけた口調で応答する。Live2D のキャラクターは、目が半開きになる。起きている時間帯は、通常の応答に戻る
- 就寝・起床の時刻は、利用者がよく話しかける時間帯に合わせて、少しずつ寄る。直近の発話から、週次で学習する ([活動時間学習バッチ](../../specs/batch/learn-user-activity.md)、[活動時間プロファイル](../../specs/term/user-activity-profile.md))
- 就寝中は、キャラクターから通知を送らず、調べものもしない ([Push 通知](push-notification.md)、[勉強](study.md))

## やらないこと

- **寝ているときに応答を止めること**: 口調と目だけを寝ぼけたものにし、応答は止めない。止めると、夜に使う人が使えなくなるため ([生活サイクル](../../specs/term/lifecycle.md))

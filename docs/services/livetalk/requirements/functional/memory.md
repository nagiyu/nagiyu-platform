# 記憶

キャラクターが、会話から利用者についての事実を覚え、関連する話題だけを思い出して話す。利用者は、覚えられていることを見て、消せる。ユースケースは[記憶を見る・消す](../use-cases/view-and-delete-memory.md)。

## 要件

- 会話から、利用者についての事実 (SELF fact) を話題 (Topic) ごとに覚える。同じ話題に、キャラクターが調べたこと (WEB fact) が同居し、話したことと調べたことがつながる ([Topic](../../specs/term/topic.md))
- 覚えるのは、バッチで畳むときである。会話の応答の中では覚えない ([集約バッチ](../../specs/batch/consolidate-conversations.md))
- 利用者が会話で言い直す (訂正・取り消す) と、古い SELF fact が新しいものに置き換わる。言い直しでない発言 (好みや事実が増えただけの発言を含む) では消さない。迷うときは消さず、古いものが残る側に倒す
- 会話では、発言に関連する話題だけを思い出す
- 覚えていることには、いつ聞いたか・いつ調べたかが付く。いつのことかは、本文に年月日で持たせる。終わったことは、終わったと書く ([会話の経路](../../specs/flow/conversation.md))
- 利用者は、覚えられていること (SELF fact) を話題ごとに見られる ([記憶画面](../../specs/screen/memory.md))
- 利用者は、覚えられていることを 1 件ずつ削除できる。削除は物理削除で、その場で話題の要約を作り直し、削除した内容は以降の応答にも要約にも残らない ([記憶 API](../../specs/api/memory.md))

## やらないこと

- **覚えたことの宣言** (応答で「覚えとくね」と言う暗黙確認): 覚えるのはバッチで畳むときで、応答で約束しても覚えるとは限らず、約束と実際がずれうるため
- **記憶の編集**: 編集しても、要約と会話履歴に古い情報が残り、キャラクターが言い続けるため
- **Tier やピン留め**: 想起を関連度で行うので、利用者に見せる必要がないため ([記憶画面](../../specs/screen/memory.md))
- **WEB fact の表示と削除**: 画面は「私について覚えていること」に限るため ([記憶画面](../../specs/screen/memory.md))
- **会話履歴の改変**: 記憶を消しても、会話履歴は書き換えない。履歴を改変する感じを避けるため ([記憶 API](../../specs/api/memory.md))
- **終わった話題の自動削除**: 終わった話題や過ぎた予定を、自動では消さない。いつのことかを本文に残して扱う

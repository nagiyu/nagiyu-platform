# 勉強

キャラクターが、知らない話題や、利用者が気にしている話題を、自分で Web から調べて覚える。ユースケースは[知らない話題を聞く](../use-cases/ask-unknown-topic.md)と、[調べたことを通知で受け取る](../use-cases/receive-research-notification.md)。

## 要件

- 調べる契機は 3 つある ([勉強バッチ](../../specs/batch/acquire.md))
    - **会話からの依頼**: 会話で、調べ済みでない外部の話題が出たとき ([勉強の依頼](../../specs/term/study-topic.md))
    - **鮮度の確認**: 会話や通知で使われた話題に、期限の切れた WEB fact があるとき ([鮮度確認の依頼](../../specs/term/freshness-check-request.md))
    - **自発リサーチ**: 利用者が気にしている話題 (care が高いもの) を起点に、角度を広げて調べる ([探索の記録](../../specs/term/exploration.md))
- 知らない話題は、LLM に即答させず、コードで「勉強しておくね」に倒す。調べ済みの話題 (WEB fact を持つ話題) は、会話で答える。利用者自身のこと、一般常識、雑談は、勉強に倒さない
- 調べた内容は、バッチで話題に畳む ([集約バッチ](../../specs/batch/consolidate-conversations.md))
- WEB fact は、揮発性の区分で期限を持ち、期限を過ぎたものだけを調べ直す。話題ごとの件数にも上限を置く ([WEB fact](../../specs/term/web-fact.md))
- 調べる回数に、利用者ごとの 1 日の上限を置く。利用者 1 人の費用が、キャラクターの数だけ増えないようにするため
- 利用者が 3 日話しかけていないキャラクターは、調べず、重要な通知も送らない。話しかけると再開する ([勉強の停止](../../specs/term/study-pause.md))
- キャラクターが就寝中のときは、調べない。利用者の活動する時間帯には、自発リサーチをしない ([生活サイクル](lifecycle.md))
- 自発リサーチの起点は、care が 1 以上の話題だけである ([探索の記録](../../specs/term/exploration.md))
    - 利用者の発言から得た事実は、角度を選ぶ手がかりにするだけで、センシティブな内容には踏み込まない
    - 起点が気分・体調・悩みのときは、解決策や公的な情報には広げず、気分転換になる軽い話題へ広げる
- 探索で得た話題は、利用者が会話で触れて care が上がるまで、ノートや通知にならない ([care](../../specs/term/care.md))

## やらないこと

- **自発リサーチだけでの care の上昇**: 自己強化して、利用者が触れていない話題が育つため ([care](../../specs/term/care.md))
- **使われていない話題の調べ直し**: 期限が来ても、会話や通知で使われない話題は調べ直さない ([鮮度確認の依頼](../../specs/term/freshness-check-request.md))

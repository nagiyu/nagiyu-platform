# 会話

利用者が文字で発言し、キャラクターが人格に沿って応答を文字と音声で返す。ユースケースは[キャラクターと話す](../use-cases/talk-with-character.md)。

## 要件

- 利用者は、文字で発言を送れる ([ホーム画面](../../specs/screen/home.md)、[チャット API](../../specs/api/chat.md))
- 応答は、文字と音声で返る。文字は作りながら順に表示され、音声は文ごとに作って順に再生される ([会話の経路](../../specs/flow/conversation.md))
- 応答は、キャラクターごとの性格・口調・好みに沿う ([キャラクター](characters.md))
- 発言に関連する話題を思い出して、応答に使う ([記憶](memory.md))
- 今日の日付 (日本時間) を踏まえて話す。終わった予定を「これから」のこととして話さない ([会話の経路](../../specs/flow/conversation.md))
- 発言と応答は会話履歴に残り、記憶の元になる ([データの保持](../non-functional/data-retention.md))
- 同意が無い利用者の会話は、サーバーも断る ([同意](consent.md))
- 危険な発言は、LLM に任せず専用の応答にする ([セーフティ](safety.md))
- 知らない話題は、即答せず調べる ([勉強](study.md))
- 同じ利用者の同時の呼び出しは 1 本まで、短時間の呼び出しの回数には上限を置く。上限に当たったときは、やわらかい文言で待たせる。LLM の課金が、再送や不具合で暴走しないようにするため ([チャット API](../../specs/api/chat.md))
- 想起・知識の判定・ノートの取得・出力の検査・親密度の更新が失敗しても、会話は続ける

## やらないこと

なし

# セーフティの横断レビュー

運用者が、全利用者のセーフティの検出を、新しい順に確かめる。ユースケースは[セーフティの横断レビューを見る](../use-cases/review-safety-events.md)。

## 要件

- `livetalk:admin` を持つ運用者は、全利用者の検出を、検出時刻の新しい順に確かめられる ([ステータス画面](../../specs/screen/status.md))
- 一覧には、検出の時刻、種類 (キーワードの検出か Moderation か)、キャラクター、検出したパターン、利用者を示す ID を出す
- 辞書の保守と、対応が妥当かの判断に使える。検出を残しても全利用者を横断して見る手段がなければ、「ログは取っているが誰も見られない」状態になるため、人間がレビューできることを実態として満たす
- 退会した利用者の検出も、匿名のまま一覧に残る ([退会とデータの削除](account-deletion.md))
- `livetalk:admin` を持たない利用者には、見せない ([権限とロール](../../specs/term/permission.md))

## やらないこと

- **発言と応答の本文を、一覧に出すこと**: 横断の一覧は、メタデータだけを扱う。個人情報を含む本文を、全利用者を横断して並べない

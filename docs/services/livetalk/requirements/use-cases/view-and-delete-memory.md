# 記憶を見る・消す

利用者が、キャラクターが自分について覚えていることを話題ごとに見て、不要な項目を 1 件ずつ消す。

## 前提

- ログインしている ([権限とロール](../../specs/term/permission.md))

## 流れ

1. 利用者が、ヘッダーのメニューから「私が覚えていること」を開く ([記憶画面](../../specs/screen/memory.md))
2. 選んでいるキャラクターが覚えていることが、話題ごとに並ぶ ([SELF fact](../../specs/term/self-fact.md))
3. 利用者が、消したい項目の削除を選ぶ
4. 確認のダイアログで、元に戻せないことを確かめて削除する ([記憶 API](../../specs/api/memory.md))
5. その話題の要約が作り直され、一覧が更新される

## 結果

- 消した内容は、以降の会話に出てこない

## 例外

- 覚えていることが無いときは、無い旨を示す
- 削除に失敗したときは、ダイアログの中にエラーを出し、閉じない
- キャラクターが調べた内容 (WEB fact) は、この画面に出ず、消せない ([記憶](../functional/memory.md))

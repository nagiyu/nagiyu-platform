# セーフティの横断レビューを見る

運用者が、全利用者のセーフティの検出を新しい順に確かめる。

## 前提

- ログインしていて、`livetalk:admin` を持つ ([権限とロール](../../specs/term/permission.md))

## 流れ

1. 運用者が、ヘッダーのメニューから「ステータス」を開く ([ステータス画面](../../specs/screen/status.md))
2. 「セーフティ横断レビュー」に、直近の検出が新しい順に並ぶ
3. 運用者が、検出の時刻、種類、キャラクター、検出したパターンを確かめる

## 結果

- 運用者は、検出の傾向と、対応が妥当かを判断できる

## 例外

- `livetalk:admin` を持たないときは、画面を見られない
- 検出がないときは、無い旨を示す
- 発言と応答の本文は、一覧に出さない ([セーフティの横断レビュー](../functional/safety-review.md))

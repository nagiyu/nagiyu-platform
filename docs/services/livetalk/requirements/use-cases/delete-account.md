# 退会してデータを消す

利用者が、リブトークに残る自分のデータをすべて消して、サービスから抜ける。

## 前提

- ログインしていて、`livetalk:chat` を持つ ([権限とロール](../../specs/term/permission.md))

## 流れ

1. 利用者が、ヘッダーのアカウントメニューから「退会・データ削除」を選ぶ ([ホーム画面](../../specs/screen/home.md))
2. 確認のダイアログに、削除する範囲と、元に戻せないことが示される。セーフティの検出の記録だけは匿名にして検出から 3 年間残し、期間が過ぎたら自動で消えることも示される
3. 利用者が、理解したことにチェックして「退会・削除する」を押す
4. リブトークが、利用者のデータを削除する ([アカウント API](../../specs/api/account.md))
5. 成功すると、Auth のサインアウトに移る

## 結果

- 会話履歴、記憶、ノート、通知の記録など、利用者のデータが消える
- セーフティの検出の記録だけが、利用者から切り離されて残る

## 例外

- 削除に失敗したときは、ダイアログの中にエラーを出し、閉じない。押し直せる
- 同意が無くても、退会できる ([同意](../functional/consent.md))
- Google アカウント、ほかのサービスのデータ、ロールは対象にしない ([退会とデータの削除](../functional/account-deletion.md))

# 通知を有効にする

利用者が、キャラクターからの Push 通知を受け取れるように、端末で通知を許可して購読する。

## 前提

- ログインしていて、`livetalk:chat` を持つ ([権限とロール](../../specs/term/permission.md))
- ホーム画面を開いている
- Push に対応するブラウザである

## 流れ

1. 利用者が、ホーム画面の「お知らせを受け取る」を押す。ホーム画面に追加した状態で通知が未許可なら、案内の「通知を許可する」を押してもよい ([ホーム画面](../../specs/screen/home.md))
2. ブラウザが、通知の許可を尋ねる
3. 利用者が許可すると、端末が購読として登録される ([購読の API](../../specs/api/push.md))
4. 表示が「お知らせを受け取る設定になっているよ」に変わる

## 結果

- 利用者は、すべてのキャラクターからの通知を、この端末で受け取れる ([Push 通知](../functional/push-notification.md))

## 例外

- ブラウザが通知を拒否しているときは、ブラウザの設定から許可するよう示す
- 失敗したときは、あとで試すよう示す
- Push に対応しないブラウザでは、ボタンを出さない
- 案内は「あとでね」で閉じると、3 日は出ない

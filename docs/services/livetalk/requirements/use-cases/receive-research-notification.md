# キャラクターが調べたことを通知で受け取る

キャラクターが利用者の興味のある話題を調べ、見つけたことを Push 通知で知らせる。タップすると、キャラクターの第一声で共有される。

## 前提

- [通知が有効](enable-notifications.md)になっている (Push の購読がある)
- 利用者が話題について会話したことがある。キャラクターが調べる話題は、利用者が会話で触れたものから選ぶ ([勉強](../functional/study.md))

## 流れ

1. キャラクターが、利用者の興味のある話題を自分で調べる ([勉強バッチ](../../specs/batch/acquire.md))
2. 通知バッチが、利用者の活動する時間帯に Push 通知を送る ([通知バッチ](../../specs/batch/notify.md))
3. 利用者が通知をタップする
4. 通知元のキャラクターでホーム画面が開き、第一声として通知の本文が出る。返信の下書きが入力欄に入る。送信は利用者が押す ([通知から会話への経路](../../specs/flow/notification-open.md))

## 結果

- 利用者は、キャラクターが調べたことを、キャラクターの言葉で受け取る
- 利用者が下書きを送ると、会話が始まる

## 例外

- キャラクターが就寝中の間は、通知を送らない
- 利用者が 3 日話しかけていないキャラクターは、重要な通知を送らず、平常の通知は話題名のない文面になる ([勉強の停止](../../specs/term/study-pause.md))
- 通知に反応がないと、次の通知までの間隔が延びる
- 通知をタップせずに画面を開いても、そのキャラクターの未消化の通知は第一声になる。ほかのキャラクターの通知は「連絡が来てるよ」と知らせるだけで、そのキャラクターに切り替えるまで保持する

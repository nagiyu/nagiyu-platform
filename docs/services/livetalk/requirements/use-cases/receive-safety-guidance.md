# 危険な発言のあとの案内を受ける

利用者が自殺・自傷をほのめかす発言をしたとき、キャラクターが心配を伝え、相談できる窓口を案内する。

## 前提

- [キャラクターと話す](talk-with-character.md)の前提と同じ

## 流れ

1. 利用者が、自殺や自傷、絶望などを示す発言を送る
2. リブトークが、LLM を使わず、キャラクターの口調で心配を伝える応答を返す ([セーフティ](../../specs/term/safety.md))
3. 応答に続けて、相談できる場所のダイアログが開き、窓口が並ぶ ([ホーム画面](../../specs/screen/home.md))
4. 利用者がダイアログを閉じて、会話に戻る

## 結果

- 利用者は、窓口の名前と連絡先を知れる
- 検出の記録が残り、運用者が確かめられる ([セーフティの横断レビューを見る](review-safety-events.md))

## 例外

- キャラクターの応答が出力の検査で止められたときも、差し替えの応答と窓口を示す
- 検査の呼び出しが失敗したときは、止めずに通常の応答を通す
- 発言に当たる語を含んでいても、危険の意図がなければ中断することがある。安全側に倒しているため ([セーフティ](../functional/safety.md))

# 利用規約に同意する

利用者が、利用規約・プライバシーポリシーと 18 歳以上であることに同意して、会話を始める。規約が改定されたときは、同意を取り直す。

## 前提

- ログインしている ([権限とロール](../../specs/term/permission.md))
- 今の版の規約とプライバシーポリシーに、まだ同意していない

## 流れ

1. 利用者がホーム画面を開くと、同意のダイアログが出て、入力欄が使えない ([ホーム画面](../../specs/screen/home.md))
2. 利用者が、規約とプライバシーポリシーを読む。全文は別のタブで開ける ([利用規約](../../specs/screen/terms.md)、[プライバシーポリシー](../../specs/screen/privacy.md))
3. 利用者が、規約・プライバシーポリシーへの同意と、18 歳以上である旨の自己申告にチェックする
4. 「利用開始」を押すと、同意が記録され、入力欄が使えるようになる ([同意 API](../../specs/api/consent.md))

## 結果

- 同意した版と日時が、利用者ごとに記録される ([同意](../../specs/term/consent.md))

## 例外

- 規約かプライバシーポリシーが改定されたときは、改定のお知らせとして同じダイアログが出る。変わった文書ごとに、改定の要点が示され、変わった文書の分だけ同意を取り直す。18 歳以上の申告が記録済みなら、取り直さない
- 送信に失敗したときは、ダイアログの中にエラーを出す。ダイアログは閉じず、もう一度押せる
- 同意が無いと、会話はサーバーも断る。ダイアログは開き直される

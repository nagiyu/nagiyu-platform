# ノートを読む

利用者が、キャラクターが贈ってくれたノートを一覧で見て、1 件を開いて読む。

## 前提

- ログインしている ([権限とロール](../../specs/term/permission.md))

## 流れ

1. 利用者が、ヘッダーのメニューから「ノート」を開く ([ノート一覧画面](../../specs/screen/notes.md))
2. 選んでいるキャラクターのノートが、贈られた日の新しい順に並ぶ
3. 利用者が、読みたいノートを選ぶ
4. 手紙の文面と、調べた内容、出典が表示される ([ノート詳細画面](../../specs/screen/note-detail.md))

## 結果

- 利用者は、キャラクターがなぜ調べたのか、何がわかったのかを読める
- ノートの手紙の文面は、贈った時点のまま変わらない。調べた内容は、開くたびに最新になる ([ノート](../../specs/term/note.md))

## 例外

- ノートが無いときは、無い旨を示す
- 取得に失敗したときは、エラーを出す
- ノートを編集・削除する操作は無い ([ギフトノート](../functional/gift-note.md))

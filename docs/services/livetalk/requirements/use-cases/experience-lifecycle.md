# キャラクターの生活サイクルを体験する

時間帯によって、キャラクターの応答が変わる。寝ている時間帯に話しかけると、寝ぼけた口調で返ってくる。

## 前提

- [キャラクターと話す](talk-with-character.md)の前提と同じ

## 流れ

1. 利用者が、キャラクターの就寝中の時間帯に話しかける
2. キャラクターは、短く、ぼんやりした寝ぼけた口調で返す。Live2D のキャラクターは、目が半開きになる ([生活サイクル](../functional/lifecycle.md))
3. キャラクターの起床後に話しかけると、通常の応答に戻る

## 結果

- 利用者は、キャラクターが自分と同じ時間軸で生活していると感じられる

## 例外

- 寝ていても、応答は止まらない
- 利用者がよく話しかける時間帯に合わせて、キャラクターの就寝・起床時刻が少しずつ寄る ([活動時間学習バッチ](../../specs/batch/learn-user-activity.md))
- 利用者の活動から学習するまでは、既定の就寝・起床時刻で寝ぼけるかを決める

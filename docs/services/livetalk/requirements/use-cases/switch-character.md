# キャラクターを切り替える

利用者が、話す相手のキャラクターを選び直す。

## 前提

- ホーム画面を開いている ([ホーム画面](../../specs/screen/home.md))
- 応答を待っていない

## 流れ

1. 利用者が、「キャラ: {名前}」のボタンを押す
2. 登録されているキャラクターが、名前、説明、モデルと音声の名前とともに並ぶ
3. 利用者が、キャラクターを選んで「決定」を押す
4. ホーム画面が、選んだキャラクターの描画、記憶、ノート、生活サイクルに切り替わる

## 結果

- 以降の会話・記憶・ノート・通知は、選んだキャラクターのものになる
- 選んだキャラクターは、この端末に残る ([キャラクター](../../specs/term/character.md))

## 例外

- 「キャンセル」で、切り替えずに閉じる
- 応答を待っている間は、切り替えられない
- 通知をタップして開いたときは、通知元のキャラクターに自動で切り替わる ([通知から会話への経路](../../specs/flow/notification-open.md))

詳しくは[キャラクターの切り替え](../functional/characters.md)を参照。

# 知らない話題を聞く

利用者がキャラクターのまだ知らない話題を聞くと、キャラクターは即答せず「勉強しておくね」と返し、あとで調べて答える。

## 前提

- [キャラクターと話す](talk-with-character.md)の前提と同じ

## 流れ

1. 利用者が、キャラクターがまだ調べていない外部の話題 (新作の作品、最近の出来事など) を聞く
2. リブトークは、話題を調べる依頼を積み、LLM に答えさせず「勉強しておくね」と返す ([勉強の依頼](../../specs/term/study-topic.md))
3. 勉強バッチが、Web から調べる ([勉強バッチ](../../specs/batch/acquire.md))
4. 集約バッチが、調べた内容を話題 (Topic) に畳む ([集約バッチ](../../specs/batch/consolidate-conversations.md))
5. 次の会話か通知で、キャラクターが調べたことを話す

## 結果

- キャラクターが、調べたことを覚えている

## 例外

- 調べ済みの話題は、勉強に倒さず会話でそのまま答える
- 利用者自身のこと、一般常識、雑談は、勉強に倒さない
- 利用者が 3 日話しかけていないキャラクターは、調べない。話しかけると再開する ([勉強の停止](../../specs/term/study-pause.md))
- 調べものには 1 日の回数の上限がある。使い切った日は、その日の残りは調べない

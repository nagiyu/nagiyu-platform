# キャラクターと話す

利用者が文字で発言し、キャラクターから応答を文字と音声で受け取る。

## 前提

- ログインしていて、`livetalk:chat` を持つ ([権限とロール](../../specs/term/permission.md))
- [同意](agree-to-terms.md)が済んでいる

## 流れ

1. 利用者が、ホーム画面の入力欄に発言を入力して送る ([ホーム画面](../../specs/screen/home.md))
2. リブトークが、発言に関連する話題を思い出し、キャラクターの人格で応答を作る ([会話の経路](../../specs/flow/conversation.md))
3. 応答が文字で順に表示され、文ごとに作った音声が順に再生される。音声に合わせてキャラクターの口が動く
4. 発言と応答が会話履歴に残る

## 結果

- 利用者は、キャラクターの応答を文字と音声で受け取る
- 会話の内容は、あとで記憶 ([記憶を見る・消す](view-and-delete-memory.md)) とノート ([ノートを読む](read-notes.md)) の元になる

## 例外

- 危険な発言のときは、キャラクターの口調の応答と相談先を示す ([危険な発言のあとの案内を受ける](receive-safety-guidance.md))
- 知らない話題のときは、「勉強しておくね」と返す ([知らない話題を聞く](ask-unknown-topic.md))
- 同意が無いときは、会話を断り、同意のダイアログを開き直す
- 短時間に呼び出しすぎたとき、別の応答を処理しているときは、やわらかい文言を出して待たせる。入力欄の文章は残る
- 失敗したときは、共通の文言を出し、入力欄の文章を残す

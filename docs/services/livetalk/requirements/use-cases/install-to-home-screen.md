# ホーム画面に追加する

利用者が、ブラウザで開いているリブトークを、端末のホーム画面に追加して、アプリのように開けるようにする。

## 前提

- ホーム画面を開いている
- ブラウザで開いている (ホーム画面から開いていない)
- [同意](agree-to-terms.md)が済んでいる

## 流れ

1. 利用者がホーム画面を開くと、キャラクターの言葉で、ホーム画面に追加する案内が出る ([ホーム画面](../../specs/screen/home.md))
2. iOS では、共有ボタンから「ホーム画面に追加」を選ぶ手順が示される。それ以外では、「ホーム画面に追加する」のボタンを押す
3. 利用者が追加する
4. 以降は、ホーム画面のアイコンから開く ([PWA](../../specs/term/pwa.md))

## 結果

- 利用者は、ホーム画面から直接リブトークを開ける
- ホーム画面に追加した状態では、通知を許可する案内が出る ([通知を有効にする](enable-notifications.md))

## 例外

- 「あとでね」で閉じると、3 日は案内を出さない
- 応答かエラーが画面に出たときは、その場の案内を閉じる。次に開いたときは、また出る
- 追加しなくても、ブラウザのままで会話できる ([ホーム画面への追加](../functional/pwa-install.md))

# 勉強の停止 (3 日ルール)

利用者が 72 時間以上話しかけていないキャラクターの勉強と、話題を使う通知を止める決まり。

## 説明

- 利用者の最後の発話からちょうど 72 時間たった時点で止まる。発話が一度もなければ止まっている。キャラクターの発話は「話した」に数えない
- 話しかけると、次のバッチの回から再開する
- 止まっている間の挙動

| バッチ | 挙動 |
|---|---|
| 勉強バッチ | その組を全部飛ばす。1 日の枠を等分する「勉強中の人数」にも数えない |
| 通知バッチ | 話題を使わない。重要通知は出さず、平常通知は話題名の入らない文面だけにする |

## 理由

- 勉強の対象は、lifecycle のあるキャラクターの組で、一度作られると退会まで消えない。止める決まりがないと、話さなくなった利用者のためにも、リサーチの費用をかけ続ける
- 重要通知も同じ条件で止める。勉強が止まったあとも出し続けると、情報が更新されず、延期や中止を拾えないまま「もうすぐある」と通知しうる
- 平常通知は止めず、話題名を入れない文面だけにする。平常通知の文面は、「見つけたよ」「調べておいたよ」と、勉強したことを前提にしている。止めずに文面だけを変えれば、離れた利用者を追いかけない姿勢を保ったまま、勉強していない事実を言わずに済む ([通知バッチ](../batch/notify.md))

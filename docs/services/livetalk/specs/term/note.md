# ノート

キャラクターが利用者に贈る「手紙」。[Topic](./topic.md) を参照する記録で、贈った瞬間の文面は変わらない。

## 説明

- 持ち物は、参照する Topic、贈った時点の主題、手紙の文面 (headline)、利用者の感想 (後から付く)
- 中身 (調べた内容・出典) は持たず、詳細画面が Topic の最新を都度読む
- 作るのは集約バッチの後段。条件は[集約バッチ](../batch/consolidate-conversations.md)を参照
- 1 つの Topic につき 1 つまで
- 会話には、直近 7 日以内に贈った最大 3 件を文脈として渡し、利用者の感想にキャラクターが反応できるようにする

## 理由

- ノートは、キャラクターから利用者への贈り物である。事実の報告書ではなく、「なぜ調べたか (SELF fact)」を根拠に、調べた内容 (WEB fact) を贈る手紙にする。同じ Topic に SELF fact と WEB fact が同居するので、根拠をつけて語れる
- 贈った瞬間の文面は、共有の記録として変えない。中身 (調べた内容・出典) は持たず、詳細画面が生きた Topic を都度読む
- 生成しないと判断した時刻を、Topic ごとに別のアイテムで記録する。記録がないと、毎時同じ候補を LLM に評価させ直し、入力が変わっていないのに呼ぶ無駄が出る
    - 評価し直す条件を「新しい WEB fact が増えたか」にしたのは、ノートが SELF fact と WEB fact の合成で、評価の入力のうち変わりうるのが WEB fact だからである。集約の置き換えも新しい事実を作るので、この条件に乗る。SELF fact だけが増えたときは、評価し直さない
    - 別のアイテムにするのは、Topic のヘッダを集約が楽観ロックで書き換えるためである

# 日次サマリー

システムが、取引所ごとの直近の取引日について、全ティッカーの日次サマリーを毎時生成して保存する。利用者は、確度とあわせて一覧で見る。ユースケースは[日次サマリーと確度を一覧する](../use-cases/browse-summaries.md)。

## 要件

### 生成

- 毎時、取引所ごとに、直近の取引日 (対象日) の全ティッカーの日次サマリーを生成して保存する。内容は、始値・高値・安値・終値・出来高と、固定のパターンの判定 ([サマリーバッチ](../../specs/batch/summary.md)、[日次サマリー](../../specs/term/daily-summary.md))
- 取引所が引けたかを判定せず、毎時すべての取引所を対象にする
- 4 本値と、全パターンの判定がそろっているサマリーは、日足の取得も保存もしない。そろっていなければ、毎時の実行で日足を取り直す
- 対象日の足がない日 (祝日などの休場日) は、サマリーを作らない。実行が翌営業日の取引時間中にずれ込んでも、進行中の足ではなく、対象日の足を使う
- 個別のティッカーや取引所の失敗は、その処理を飛ばして、残りの処理を続ける ([信頼性](../non-functional/reliability.md))
- 1 件以上保存した回の終わりに、確度の算出を起動する。1 件も保存しなかったときは起動しない ([確度](forecast.md))
- アラートを判定するバッチとは独立した、別のバッチとして動かす ([アラート](alerts.md))
- 管理者 (`stocks:manage-data` 権限) は、サマリー画面の「サマリー更新」で、生成を手動で起動できる。完了は待たない ([サマリー API](../../specs/api/summaries.md))
- パターンは固定の定義で持ち、判定の結果は判断軸の材料として使う ([判断軸](../../specs/term/axis.md))

### 一覧

- 利用者 (`stocks:read` 権限) が、取引所ごとに、銘柄の確度・点灯したパターン数・アラート数・保有を一覧で見られる ([サマリー画面](../../specs/screen/summaries.md))
- 取引所で絞り込める。方向と荒れは、確率で並べ替えられる
- 確度がない日付や、確度を算出できなかった銘柄でも、ティッカーの行とチャートは表示する

## やらないこと

- **祝日マスターを持つこと**: 休場日は、データソースの日足が持つ日付で判定する。足がある日だけが取引日で、毎年の祝日の更新が要らないため
- **AI による解析**: 理由は[目的](../purpose.md)の「扱わない範囲」を参照

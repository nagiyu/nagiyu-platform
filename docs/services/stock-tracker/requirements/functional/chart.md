# チャート

利用者が、取引所とティッカーを選んで株価チャートを見る。時間枠の切り替えと自動更新ができ、保有株式の平均取得価格とアラートのしきい値をチャートに重ねて見られる。ユースケースは[チャートを見る](../use-cases/view-chart.md)と[銘柄の状況をまとめて見て、その場で直す](../use-cases/review-ticker.md)。

## 要件

- 取引所とティッカーを選んで、その銘柄の足をローソク足のチャートで見られる ([チャート API](../../specs/api/chart.md)、[トップ画面](../../specs/screen/home.md))
- 時間枠 (1 分足・5 分足・1 時間足・日足) と表示本数を切り替えられる
- 自動更新を入れると、チャートが一定間隔で読み直され、描き直される。切ると止まる
- 保有株式があれば平均取得価格を、有効なアラートがあればしきい値 (上限・下限) を、チャートに重ねて見られる
- 銘柄を選ぶと、チャートに加えて、日次サマリー (確度を含む)・保有株式・アラートを同じ画面に出す。保有株式とアラートは、その場で追加・編集・削除できる ([保有株式](holdings.md)、[アラート](alerts.md))
- 欄は別々に読み込み、1 つの失敗でほかの欄の表示を止めない
- 取引所・ティッカー・時間枠を問い合わせで指定して、画面を開ける。通知から開くときは、通知元のアラートの取引所とティッカーが選ばれた状態で開く ([アラート通知の経路](../../specs/flow/alert-notification.md))
- 足は、取引所の価格の取得元の設定によらず TradingView から取る ([価格の取得元](../../specs/term/price-source.md))

## やらないこと

なし

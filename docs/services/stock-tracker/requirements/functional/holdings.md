# 保有株式

利用者が、自分の保有株式を登録し、平均取得価格を基準に売りの目標価格を決める。ユースケースは[保有株式を管理し、目標価格を決める](../use-cases/manage-holdings.md)。

## 要件

- 保有する銘柄の保有数・平均取得価格・通貨を登録し、編集し、削除できる。同じ銘柄の保有株式は 1 件だけ ([保有株式 API](../../specs/api/holdings.md)、[保有株式画面](../../specs/screen/holdings.md))
- 保有株式は利用者ごとに分かれ、ほかの利用者のものは読み書きできない ([アクセス制御](access-control.md))
- 保有株式の登録・編集・削除は、保有株式画面と、トップ画面の保有株式の欄のどちらからでもできる ([トップ画面](../../specs/screen/home.md))
- 平均取得価格を基準に、売りアラートの目標価格を決められる。保有株式画面から売りアラートを設定するときの入力の基準は、[保有株式画面](../../specs/screen/holdings.md)にある ([アラート](alerts.md))
- 保有株式を削除すると、その銘柄の売りアラートも削除する。削除の確認で、削除される売りアラートを先に示す。保有株式を削除する API 自体は、アラートに触れない
- 保有している銘柄は、平均取得価格がチャートに重なる ([チャート](chart.md))

## やらないこと

なし

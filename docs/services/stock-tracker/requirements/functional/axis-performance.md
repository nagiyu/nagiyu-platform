# 判断軸の成績

利用者が、確度が実際にその確率で当たっているかと、判断軸ごとの成績を、継続的に確かめられる。ユースケースは[判断軸の成績を確かめる](../use-cases/check-axis-performance.md)。

## 要件

- 問い (方向・荒れ・市場の荒れ)、集計期間、市場を切り替えて、採点済みの予測の成績を見られる ([判断軸の成績画面](../../specs/screen/axis-performance.md)、[判断軸の成績 API](../../specs/api/axis-performance.md))
- 確度の成績として、確率帯ごとの件数・予測の平均・実際の的中率を見られる。確度が実際にその確率で当たっているかを確かめるためである ([確度](forecast.md))
- 軸ごとの成績として、件数・的中率・ふだんとの差・現在の重みを見られる。方向は、平均超過リターンも見られる
- 件数が少ない確率帯と軸は、参考として区別して出す
- `stocks:read` 権限があれば見られる。専用の権限は持たない ([権限とロール](../../specs/term/permission.md))
- 採点済みの予測がない期間は、その旨を出す

## やらないこと

なし

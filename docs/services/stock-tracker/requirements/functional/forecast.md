# 確度

システムが、判断軸から、翌営業日についての確度を確率で出し、翌営業日の実績で採点し、その成績で重みを更新し続ける。利用者は、確度とその出どころを見て、人が検討する。ユースケースは[確度の内訳を確かめる](../use-cases/view-forecast-detail.md)。

## 要件

### 問い

確度は、次の 3 つの問いに対して、当日の引け後に出す。答え合わせは、翌営業日の引け値で行う (保有期間 1 営業日)。当たりの条件と対象は[問い](../../specs/term/question.md)を参照する。

| 問い | 確度の意味 |
|---|---|
| 方向 | 銘柄が、同じ市場の登録銘柄の平均を上回る確率 |
| 荒れ | 銘柄が、平常より荒れる確率 |
| 市場の荒れ | 市場全体が、平常より荒れる確率 |

- 市場は、日本 (JP) と米国 (US) の 2 つ。取引所が属する市場は、取引所の設定で決まる ([取引所・ティッカーの管理](master-data.md))。市場が未設定の取引所は、確度の算出の対象から外れる

### 判断軸

- 判断軸は、当日までの OHLCV (とそこから算出した値) だけを使って、機械的に算出できる条件または値とする。軸ごとに、使う問いを定義として持つ ([判断軸](../../specs/term/axis.md))
- 複合パターン軸を、独立した軸として持つ。単一軸の重みづけの合計だけでは、複数のパターンが重なったときにだけ出る効果を表せないため
- 判断軸は後から追加でき、追加した軸にも同じ採点と重みづけを適用する ([確度の整合性](../non-functional/forecast-integrity.md))

### 合成

- 重みは、予測日より前に確定した成績だけで決める (ウォークフォワード)
- 件数の少ない軸の重みは、ゼロに寄せる
- 軸どうしの相関を考慮して合成する。単純な多数決や合計にしない
- 局面によって当たり外れが反転するため、重みは固定せず、直近の成績を反映して更新し続ける
- 確度と一緒に、どの軸も効いていないときの確率 (基準値。画面上は「ふだん」) を出す。基準値に近い範囲は「中立」として区別する
- 各軸の寄与の合計は、確度とふだんの差に一致する
- 方式の理由は[確度](../../specs/term/forecast.md)、[問い](../../specs/term/question.md)、[判断軸](../../specs/term/axis.md)の理由を参照する

### 算出と採点

- 確度は、日次サマリーがそろった市場について、取引所の引け後に算出する。算出は、毎時の起動と、日次サマリーを 1 件以上保存した回の終わりの起動で進む ([確度算出バッチ](../../specs/batch/forecast.md))
- 確度は、予測時点の値として記録し、後から書き換えない。答え合わせは、確度に追記する
- 確度の算出や採点に失敗しても、日次サマリーの保存と表示は続ける ([信頼性](../non-functional/reliability.md))
- 採点から外すものがある。データの欠落や売買停止をまたぐ銘柄と、株式分割をまたぐなどの極端なリターンの銘柄 ([確度算出バッチ](../../specs/batch/forecast.md)、[問い](../../specs/term/question.md))
- 稼働を始めるとき、または過去の成績を作り直すときは、既存の日次サマリーの履歴から、確度・採点・重みをさかのぼって算出できる。既存の日次サマリーは、読むだけで書き換えない

### 成績の指標

- 軸ごと・問いごとに、件数 (点灯型なら点灯回数)、点灯時の的中率と基準値との差、方向は点灯時の平均超過リターンを持つ
- 合成した確度は、確率帯ごとの件数と実際の的中率を持つ。「60% と出したものが実際に 6 割当たっているか」を確かめられる ([判断軸の成績](axis-performance.md))

### 市場の荒れ予報

- 市場 (JP・US) ごとに、翌営業日に市場全体が平常より荒れる確率を出し、サマリー画面に出す。採点済みの日数が少ない間は、参考値と明示する ([確度](../../specs/term/forecast.md))

### 表示

- 確度がない日付や、確度を算出できなかった銘柄は、理由を示す。そのときも、日次サマリー・チャート・アラートの作成は、通常どおり使える
- 確度は、予測時点の値として、基準日を添えて出す。表記は、画面をまたいで揃える ([確度](../../specs/term/forecast.md))

## やらないこと

# 判断軸の成績を確かめる

利用者が、判断軸の成績画面で、確度が実際にその確率で当たっているかと、軸ごとの成績を、問い・期間・市場を切り替えて確かめる。

## 前提

- ログインしている。`stocks:read` 権限を持つ ([アクセス制御](../functional/access-control.md))

## 流れ

1. 利用者が、判断軸の成績画面を開く ([判断軸の成績画面](../../specs/screen/axis-performance.md))
2. サービスが、既定の問い・期間・市場で、採点済みの予測の成績を読む ([判断軸の成績 API](../../specs/api/axis-performance.md))
3. 利用者が、問い (方向・荒れ・市場の荒れ)、集計期間、市場を切り替える。サービスが、選んだ値で読み直す
4. 画面に、確率帯ごとの件数と実際の的中率、軸ごとの成績が出る。出る項目は[判断軸の成績画面](../../specs/screen/axis-performance.md)にある

## 結果

- 利用者は、「60% と出したものが実際に 6 割当たっているか」と、どの軸が効いているかを確かめられる

## 例外

- 採点済みの予測がない期間は、その旨を出す
- 件数が少ない確率帯と軸は、参考として区別して出す

# アラートを絞り込む

利用者が、アラート一覧画面で、取引所とモードを指定して、見たいアラートだけに絞る。

## 前提

- ログインしている。`stocks:read` 権限を持つ ([アクセス制御](../functional/access-control.md))
- アラートが 1 件以上登録されている

## 流れ

1. 利用者が、アラート一覧画面を開く ([アラート一覧画面](../../specs/screen/alerts.md))
2. 利用者が、取引所とモード (買い・売り) の一方または両方を指定する
3. サービスが、条件に合うアラートだけを一覧に残す。絞り込みは画面の中で行い、サーバーへは問い合わせない
4. 利用者が、「クリア」で絞り込みを外す

## 結果

- 利用者は、取引所やモードを指定して、自分のアラートの一部だけを見られる
- 絞り込みの状態は、画面の中にだけ持つ。URL には反映せず、画面を開き直すと外れる

## 例外

- 条件に合うアラートがないときは、その旨を出す

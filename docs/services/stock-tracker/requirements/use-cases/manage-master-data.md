# 取引所とティッカーを管理する

管理者が、取引所とティッカーのマスタを作り、編集し、削除する。利用者がチャートやアラートで選べる銘柄は、ここで決まる。

## 前提

- ログインしている。`stocks:manage-data` 権限を持つ。現在は `stock-admin` ロールだけが持つ ([アクセス制御](../functional/access-control.md))

## 流れ

1. 管理者が、取引所管理画面を開く ([取引所管理画面](../../specs/screen/exchanges.md))
2. 管理者が、取引所を作る、または編集する。名前・タイムゾーン・取引時間・価格の取得元・市場を決める ([取引所 API](../../specs/api/exchanges.md))
3. 管理者が、ティッカー管理画面を開く ([ティッカー管理画面](../../specs/screen/tickers.md))
4. 管理者が、シンボル・銘柄名・取引所を指定してティッカーを作る。銘柄名を編集する ([ティッカー API](../../specs/api/tickers.md))
5. 管理者が、取引所やティッカーを削除する

## 結果

- 作った取引所とティッカーを、利用者がチャート・保有株式・アラートで選べる
- 日次サマリーの生成の対象になる ([日次サマリー](../functional/daily-summary.md))。市場を決めた取引所は、確度の算出の対象にもなる ([確度](../functional/forecast.md))

## 例外

- `stocks:manage-data` 権限がないときは、画面は一覧を読まず、権限エラーを出す
- 削除は、関連するデータ (取引所のティッカー、ティッカーの保有株式やアラート) を確認も削除もしない

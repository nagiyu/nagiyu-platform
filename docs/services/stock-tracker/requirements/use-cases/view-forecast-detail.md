# 確度の内訳を確かめる

利用者が、1 つの銘柄の確度を、ふだんの割合・同じ確率帯の過去実績・点灯した軸の内訳とあわせて見る。表示された確率を信じてよいかと、何が確率を動かしたかを判断できるようにする。

## 前提

- ログインしている。`stocks:read` 権限を持つ ([アクセス制御](../functional/access-control.md))
- 銘柄の日次サマリーが作られている

## 流れ

1. 利用者が、サマリー画面の銘柄の行、またはトップ画面のサマリーの「詳細」を押す ([サマリー画面](../../specs/screen/summaries.md)、[トップ画面](../../specs/screen/home.md))
2. サービスが、詳細ダイアログを開き、その銘柄の確度を読む ([確度 API](../../specs/api/forecasts.md))
3. ダイアログに、方向と荒れの確率、ふだんの割合、同じ確率帯の過去実績、軸ごとの内訳 (点灯、確率への寄与、過去の成績) が出る。日足のチャートも見られる
4. 利用者が、方向と荒れの内訳を切り替える。アラートをここから設定することもできる ([アラートを設定する](set-alert.md))

## 結果

- 利用者は、確度の根拠を、軸ごとに説明できる状態で確かめられる

## 例外

- 確度がないときは、理由 (確度なし、または履歴不足) を示す。そのときもチャートとアラートの作成は、通常どおり使える

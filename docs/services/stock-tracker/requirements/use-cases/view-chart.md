# チャートを見る

利用者が、取引所とティッカーを選び、時間枠を切り替えて株価チャートを見る。自動更新を入れると、チャートが一定間隔で読み直される。

## 前提

- ログインしている。`stocks:read` 権限を持つ ([アクセス制御](../functional/access-control.md))
- 取引所とティッカーが登録されている ([取引所・ティッカーの管理](../functional/master-data.md))

## 流れ

1. 利用者が、トップ画面を開く ([トップ画面](../../specs/screen/home.md))
2. 取引所とティッカーを選ぶと、サービスが、その銘柄の足をチャートに出す ([チャート API](../../specs/api/chart.md))
3. 利用者が、時間枠と表示本数を切り替える。サービスが、選んだ条件でチャートを読み直す
4. 利用者が、自動更新を入れる。サービスが、チャートを一定間隔で読み直し、描き直す
5. 保有株式があれば平均取得価格が、有効なアラートがあればそのしきい値が、チャートに重なって出る ([チャート](../functional/chart.md))

## 結果

- 利用者は、選んだ銘柄の価格の動きを、選んだ時間枠で見られる
- 自動更新を切るまで、チャートは読み直され続ける

## 例外

- チャートを取得できないときは、チャートの領域にエラーを出す。ほかの欄は表示する
- 取引所もティッカーも選んでいないときは、選択を促す表示を出す

# 保有株式を管理し、目標価格を決める

利用者が、保有している銘柄の数量と平均取得価格を登録し、平均取得価格を基準に、売りのアラートの目標価格を決める。

## 前提

- ログインしている。`stocks:write-own` 権限を持つ ([アクセス制御](../functional/access-control.md))
- 銘柄のティッカーが登録されている

## 流れ

1. 利用者が、保有株式画面、またはトップ画面の保有株式の欄を開く ([保有株式画面](../../specs/screen/holdings.md)、[トップ画面](../../specs/screen/home.md))
2. 利用者が、銘柄・保有数・平均取得価格・通貨を入力して登録する。サービスが、利用者自身の保有株式として保存する ([保有株式 API](../../specs/api/holdings.md))
3. 利用者が、保有数と平均取得価格を編集する
4. 利用者が、売りアラートを設定する。目標価格は、平均取得価格を基準に決められる ([アラートを設定する](set-alert.md))
5. 利用者が、保有株式を削除する。サービスが、その銘柄の売りアラートを確認に示し、保有株式と一緒に削除する

## 結果

- 利用者は、保有株式の一覧と、平均取得価格を確かめられる。保有株式は、チャートに平均取得価格の線として重なる ([チャート](../functional/chart.md))

## 例外

- 同じ銘柄の保有株式が、すでにあるとき、登録できない
- 売りアラートの削除に失敗したものがあれば、その旨を出す。保有株式の削除は済んでいる
- `stocks:write-own` 権限がないときは、登録・編集・削除の操作が出ない

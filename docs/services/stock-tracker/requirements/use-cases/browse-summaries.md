# 日次サマリーと確度を一覧する

利用者が、取引所ごとに、銘柄の確度・点灯したパターン数・アラート数・保有を並べて見て、気になる銘柄を見つける。

## 前提

- ログインしている。`stocks:read` 権限を持つ ([アクセス制御](../functional/access-control.md))
- 取引所とティッカーが登録されている

## 流れ

1. 利用者が、サマリー画面を開く ([サマリー画面](../../specs/screen/summaries.md))
2. サービスが、取引所ごとに、直近の取引日の日次サマリーを、確度とあわせて一覧にする ([サマリー API](../../specs/api/summaries.md))。市場の荒れ予報も出す
3. 利用者が、取引所を絞り込む
4. 利用者が、方向または荒れの確率で並べ替える
5. 気になる銘柄を選ぶと、確度の詳細に進める ([確度の内訳を確かめる](view-forecast-detail.md))

## 結果

- 利用者は、銘柄ごとの翌営業日の見通しと、点灯したパターン数を一覧で比べられる

## 例外

- 確度がない日付や、確度を算出できなかった銘柄でも、ティッカーの行とチャートは表示する。確度の欄の見え方は[サマリー画面](../../specs/screen/summaries.md)にある
- 銘柄がない取引所は、その旨を出す
- 確度や市場の荒れ予報、保有・アラート数の取得に失敗しても、その部分を空にして、一覧は表示する

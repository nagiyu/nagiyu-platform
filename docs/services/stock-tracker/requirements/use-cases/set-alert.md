# アラートを設定する

利用者が、株価の条件を決めてアラートを作る。条件を満たしたときに、端末へ Web Push で通知が届く。アラートの修正・無効化・削除もここで行う。

## 前提

- ログインしている。`stocks:write-own` 権限を持つ ([アクセス制御](../functional/access-control.md))
- 通知する端末のブラウザで、通知を許可できる

## 流れ

1. 利用者が、アラート設定ダイアログを開く。アラート一覧画面、トップ画面のアラートの欄、サマリーの詳細、保有株式画面から開ける ([アラート一覧画面](../../specs/screen/alerts.md))
2. 利用者が、モード (買い・売り)、条件 (単一の価格か、範囲)、頻度 (1 分間隔・1 時間間隔)、一時通知にするか、カスタムメッセージ (任意) を決める
3. 初めて作るとき、サービスが通知の許可を求める。許可されると、通知の宛先となる購読ができる ([Push 通知 API](../../specs/api/push.md))
4. サービスが、アラートを購読とあわせて保存する ([アラート API](../../specs/api/alerts.md))
5. 利用者が、あとから条件・有効無効・一時通知・カスタムメッセージを変える、または削除する

## 結果

- アラートが有効になり、条件を満たすと通知が届く ([通知を受けて銘柄を開く](receive-alert.md))
- モードと頻度は、作ったあとには変えられない。変えたいときは作り直す

## 例外

- 通知を許可しなかったとき、エラーを出し、アラートは作らない
- 条件が入力の範囲を外れているとき、保存できず、理由を出す ([アラート](../functional/alerts.md))

# 通知を受けて銘柄を開く

アラートの条件が満たされると、利用者の端末に Web Push の通知が届く。利用者が通知を押すと、通知元の銘柄を選んだ状態でチャート画面が開く。

## 前提

- アラートが有効で、条件を持っている ([アラートを設定する](set-alert.md))
- アラートの購読が有効で、端末が通知を受け取れる

## 流れ

1. サービスが、取引所が取引時間内のあいだ、アラートの価格条件を判定する。1 分間隔のアラートは毎分、1 時間間隔のアラートは毎時 1 回判定する ([アラート](../functional/alerts.md))
2. 条件を満たすと、サービスが、アラートの購読へ通知を送る。通知には、買いか売りかとティッカー、現在価格と目標価格が出る。カスタムメッセージがあれば、本文の末尾に付く ([アラート通知の経路](../../specs/flow/alert-notification.md))
3. 端末が通知を表示する。利用者が押すまで残る
4. 利用者が通知を押すと、チャート画面が、通知元の取引所とティッカーを選んだ状態で開く ([トップ画面](../../specs/screen/home.md))

## 結果

- 利用者は、価格が条件に届いたことを、画面を開いていなくても知り、すぐにその銘柄のチャートを見られる

## 例外

- 購読が無効なとき、通知は届かない。サービスはエラーにせず、利用者が画面を開いて購読が更新されるまで、届かない回が続く
- 条件を満たしている間は、取引時間内の判定のたびに通知が届く。通知したあとも、アラートは有効のまま変わらない
- 一時通知のアラートは、期限を過ぎると無効になり、通知されなくなる ([アラート](../functional/alerts.md))

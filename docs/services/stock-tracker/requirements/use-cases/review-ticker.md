# 銘柄の状況をまとめて見て、その場で直す

利用者が、1 つの銘柄について、チャート・日次サマリー・保有株式・アラートを同じ画面で見て、保有株式とアラートはその場で追加・編集・削除する。

## 前提

- ログインしている。`stocks:read` 権限を持つ。追加・編集・削除には `stocks:write-own` 権限が要る ([アクセス制御](../functional/access-control.md))
- 取引所とティッカーが登録されている

## 流れ

1. 利用者が、トップ画面で取引所とティッカーを選ぶ ([トップ画面](../../specs/screen/home.md))
2. サービスが、チャートに加えて、その銘柄の日次サマリー (確度を含む)・保有株式・アラートを同じ画面に出す
3. 利用者が、保有株式やアラートを、画面の中で追加・編集・削除する ([保有株式を管理する](manage-holdings.md)、[アラートを設定する](set-alert.md))
4. 保存されると、サービスが保有株式とアラートを読み直す

## 結果

- 利用者は、画面を移らずに、銘柄の価格・見通し・自分の保有・通知の設定をまとめて確かめられる

## 例外

- サマリー・保有株式・アラートは、それぞれ別に読み込む。1 つの取得に失敗しても、ほかは表示する
- 日次サマリーがまだない銘柄では、サマリーの欄に取得失敗の表示が出る
- `stocks:write-own` 権限がないときは、追加・編集・削除の操作が出ない

# stock-tracker

個人投資家が、株価の動きを見て、売買のタイミングを逃さず、保有株式と翌営業日の見通しを手がかりつきで確かめるためのサービス。チャートとアラートの通知で価格の変化を追い、日次サマリーで、機械的に算出した確度と、その出どころを示す。

## 解決したい課題

売買の判断には、タイムリーな価格情報と、適切なタイミングで条件を知らせてくれる仕組みが要る。複数の銘柄を見ていると、価格がしきい値に届いた瞬間を自分で追い続けることはできない。

このサービスは次の 4 つで、判断を支える。

- **株価の可視化**: 取引所とティッカーを選び、時間枠を切り替えてチャートを見る ([チャート](functional/chart.md))
- **アラートの通知**: 価格条件を満たしたとき、Web Push で通知する ([アラート](functional/alerts.md))
- **保有株式の管理**: 平均取得価格を登録し、それを基準に売りの目標価格を決める ([保有株式](functional/holdings.md))
- **確度の提示**: 翌営業日についての確率を、点灯した軸と各軸の過去成績とあわせて示す。確度が実際にその確率で当たっているかを、継続的に確かめられる ([確度](functional/forecast.md)、[判断軸の成績](functional/axis-performance.md))

投資判断の材料は、AI の予測ではなく、機械的に算出できる判断軸と、その過去の成績から出す。サービスの趣旨は、人が日次サマリーを見て検討することである。

## 扱わない範囲

- **AI による解析と予測**: 予測力がなく、判断材料として有害なため。次の理由による
    - 約 3.5 か月分の予測 (採点済み 7,887 件) を分析したところ、翌日予測の予測リターンと実績の符号一致は 50.1% (95% 信頼区間 48.1〜52.1%) で、予測力はなかった。保有期間・閾値・確信度で絞っても、銘柄間の順位付けでも、ベースラインと変わらなかった
    - AI の出力は入力の言い換えだった。予測リターンの分散の約半分は「当日リターン + パターン合致数」で説明でき、Web 検索やチャート画像による上乗せはなかった
    - 機械的な指標には手がかりがあった。買いパターンが 2 つ以上同時に合致した銘柄日は、翌日の超過リターンが +0.89pt だった (多重検定の補正後は未確定)。値動きの大きさは、直近の値幅や出来高比から予測できた (銘柄の平常比で相関 0.23〜0.29)
    - ただし、どの手がかりも局面に依存するか、まだ確定していない。AI を使わない指標でも、評価期間の後半には効きが反転したものがあった
    - 予測力のない予測を出し続けることは、判断材料として有害である。判断軸なら、どの軸が点灯し、その軸が過去どれだけ当たっているかを説明できる
    - 手がかりを信じて組み込むと、局面が変わったときに外れ続ける。成績を溜めて重みを更新し続ける仕組みなら、効かなくなった軸は自然に重みを失い、効き始めた軸は拾える
    - OpenAI の費用は Stock Tracker 分で月 $60 程度で、その多くが Web 検索の課金だった
- **ユーザーとロールの管理**: Auth が持つ。このサービスは、ログインした利用者のロールから権限を判定するだけで、ロールを付け外しする画面を持たない ([ユーザー管理](../../auth/requirements/functional/user-management.md))

## 利用者

- **個人投資家**: 複数の銘柄を監視し、価格条件に基づく通知を受け取り、保有株式の平均取得価格と目標価格を把握したい。モバイルとデスクトップの両方から使う
- **管理者**: 取引所とティッカーのマスタを管理する。`stock-admin` ロールを持つ ([権限とロール](../specs/term/permission.md))

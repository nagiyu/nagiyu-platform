# エラーの履歴

記録されたエラーの一覧と詳細を、運用者が見られるようにする。ユースケースは[エラーの履歴を絞って見る](../use-cases/browse-errors.md)と[エラーの詳細を見る](../use-cases/view-error-detail.md)。

## 要件

- `errors:read` 権限を持つ運用者が、記録されたエラーを、発生時刻の新しい順に一覧できる ([エラー履歴一覧画面](../../specs/screen/errors.md))
- 一覧は、サービスと期間で絞り込める
- 一覧から、1 件のエラーの詳細を開ける。詳細では、メタ情報、本文、コンテキストを見られる ([エラー詳細画面](../../specs/screen/error-detail.md))
- 保存期限を過ぎて消えたエラーや、該当のないエラーは、見つからない旨を示す
- `errors:read` 権限がないときは、一覧も詳細も見られない ([アクセス制御](access-control.md))
- 一覧と詳細は、API でも読める ([エラー履歴 API](../../specs/api/errors.md))

## やらないこと

- **エラーの編集と削除**: 履歴は、起きたことの記録なので、運用者の操作では変えない。保存期限を過ぎたものだけが消える

# エラーの詳細を見る

運用者が、1 件のエラーのメタ情報、本文、コンテキストを見る。

## 前提

- Admin にログインしている
- `errors:read` 権限を持つ ([権限とロール](../../specs/term/permission.md))

## 流れ

1. 運用者が、一覧の「詳細」、または Push 通知のタップから、エラーの詳細を開く ([エラー詳細画面](../../specs/screen/error-detail.md))
2. Admin が、そのエラーのメタ情報、本文、コンテキストを示す

## 結果

- 運用者は、失敗の発生元、時刻、内容を確かめられる

## 例外

- `errors:read` 権限がないときは、履歴を読まず、権限がない旨が示される
- 保存期限を過ぎて消えたエラー、または該当のないエラーは、見つからない旨が示される

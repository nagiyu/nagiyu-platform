# エラーの履歴を絞って見る

管理者が、各サービスで記録されたエラーを、新しい順に、サービスと期間で絞って見る。

## 前提

- Admin にログインしている
- `errors:read` 権限を持つ。現在は `admin` ロールだけが持つ ([権限とロール](../../specs/term/permission.md))

## 流れ

1. 管理者が、ダッシュボードからエラー履歴を開く
2. Admin が、記録されたエラーを新しい順に一覧する ([エラー履歴一覧画面](../../specs/screen/errors.md))
3. 管理者が、サービスと期間を指定して絞り込む
4. 管理者が、見たいエラーを選んで詳細へ進む ([エラーの詳細を見る](view-error-detail.md))

## 結果

- 管理者は、見たい期間と、見たいサービスのエラーだけを時系列で確かめられる

## 例外

- `errors:read` 権限がないときは、一覧を読まず、権限がない旨が示される
- 条件に合うエラーがないときは、一覧は空になる

# エラーが記録されると Push が届く

エラーが記録されると、管理者の端末に Push 通知が届く。タップすると、ダッシュボードを介さずにそのエラーの詳細が開く。

## 前提

- 端末で通知を有効にしている ([ダッシュボードから通知を有効にする](subscribe-notifications.md))

## 流れ

1. 各サービスの失敗が、エラーとして記録される ([エラーの収集](../functional/error-collection.md))
2. Admin が、通知を購読している端末すべてに Push を送る ([エラー通知の経路](../../specs/flow/error-notification.md))
3. 管理者が、届いた通知をタップする
4. そのエラーの詳細が開く ([エラー詳細画面](../../specs/screen/error-detail.md))

## 結果

- 管理者は、失敗が起きたことと、その内容を、ダッシュボードを開かずに確かめられる

## 例外

- 通知の仕組み自身の障害を知らせる自己監視の通知は、エラーとして記録されない。タップすると、ダッシュボードが開く ([自己監視](../functional/self-monitoring.md))
- 詳細を開く権限 (`errors:read`) がないときは、詳細は見られず、権限がない旨が示される
- 通知を購読している端末がないときは、Push は送られない。エラーは履歴に残る

# ツールカタログ

この文書は、Tools にどのツールを置くかの方針を書く。置いているツールの一覧と各ツールの挙動は、[ツール一覧画面](../../specs/tools/screen/home.md)と各画面の[仕様カード](../../specs/README.md)にある。

---

## 置くツールの方針

- ブラウザの中で完結する、日常の作業で使う小さなツールを置く。入力はサーバーへ送らない
- 各ツールは独立したページにし、必要になったものから足す (優先順位は[要件定義書](./requirements.md)に従う)
- 次のカテゴリを、足すツールの目安にする

| カテゴリ | 例 |
|---------|---|
| データ変換 | JSON、XML、YAML 等のデータフォーマット変換 |
| エンコーディング | Base64、URL、Unicode 等のエンコード/デコード |
| セキュリティ | ハッシュ生成、JWT、暗号化/復号化 |
| ユーティリティ | UUID 生成、タイムスタンプ変換、乗り換え案内変換等の汎用ツール |
| デザイン | カラーコード変換、画像処理等 |

新しいツールを足すときは、そのツールの画面カードを作り、ツール一覧画面のカードにも足す。

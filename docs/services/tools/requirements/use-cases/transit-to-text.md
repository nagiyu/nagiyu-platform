# 乗り換え案内を整形して送る

利用者が、乗り換え案内アプリで調べた経路を、必要な項目だけに整え、メモやチャットに貼れる形にする。

## 前提

- 乗り換え案内アプリで、経路のテキストを共有かコピーできる
- 共有シートから始めるときは、スマートフォンに Tools を追加してある (共有先に出るかはブラウザと OS が決める)

## 流れ

1. 利用者が、乗り換え案内アプリの経路を共有シートで Tools へ渡す。または、コピーして乗り換え変換ツールを開き、貼り付けるか「クリップボードから読み取り」を押す ([乗り換え変換ツール](../functional/transit-converter.md))
2. 共有で来たときは、共有された内容が入力欄に入った状態でツールが開く。自動では変換しない
3. 利用者が、出力に含める項目を選ぶ。選んだ項目は次回も使われる
4. 利用者が「変換」を押す。整形された結果が出る
5. 利用者が「コピー」を押し、メモやチャットへ貼る

## 結果

- 必要な項目だけの乗り換え案内が、クリップボードにある

## 例外

- 乗り換え案内の形式でないテキストのときは、解析できない旨が示される。結果は変わらない ([乗り換え変換ツール](../functional/transit-converter.md))
- URL だけが共有されたときも、解析できない旨が示される

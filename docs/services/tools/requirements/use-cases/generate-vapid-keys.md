# Web Push の鍵を作る

Web Push 通知を実装する開発者が、VAPID キーのペアを作り、公開鍵と秘密鍵をそれぞれコピーする。

## 前提

- なし。ログインは要らない

## 流れ

1. 利用者が、VAPID キー生成ツールを開く ([VAPID キー生成ツール](../functional/vapid-generator.md))
2. 利用者が「VAPIDキーを生成」を押す
3. Tools が、鍵のペアを作って、公開鍵と秘密鍵を表示する
4. 利用者が、「公開鍵をコピー」「秘密鍵をコピー」で、それぞれ写す

## 結果

- 利用者の手元に、新しい VAPID キーのペアがある。Tools は鍵を保存しない

## 例外

- 鍵を作れなかったときは、その旨が示される

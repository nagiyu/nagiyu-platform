# 使えるツールを探す

初めて来た利用者が、どんなツールがあるかを一覧で確かめ、使いたいツールを開く。

## 前提

- なし。ログインは要らない

## 流れ

1. 利用者が、Tools を開く
2. Tools が、使えるツールをカードで並べる。各カードに名前と説明がある ([ツール一覧](../functional/tool-list.md))
3. 利用者が、使いたいツールのカードを選ぶ
4. Tools が、そのツールの画面を開く

## 結果

- 利用者が、使いたいツールの画面にいる

## 例外

- 初めての訪問では、旧バージョンからの移行を案内するダイアログが先に出る。閉じるまで画面は操作できない ([初回訪問ダイアログ](../functional/migration-dialog.md))

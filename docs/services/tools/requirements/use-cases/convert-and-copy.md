# データを整形・変換してコピーする

利用者が、JSON・Base64・URL・ハッシュ・タイムスタンプのいずれかを変換し、結果をクリップボードへ写す。

## 前提

- なし。ログインは要らない

## 流れ

1. 利用者が、[ツール一覧](../functional/tool-list.md)から、目的のツールを開く
2. 利用者が、入力を貼り付けるか、「クリップボードから読み取り」で入れる (タイムスタンプ変換は手で入れる)。ツールによっては、モードやアルゴリズム、タイムゾーンを選ぶ
3. 利用者が、変換のボタンを押す。結果が出力欄に出る
4. 利用者が「コピー」を押す

使えるツールは次のとおり。

| 目的 | ツール |
|---|---|
| JSON を整形する、圧縮する | [JSON 整形ツール](../functional/json-formatter.md) |
| テキストと Base64 を相互に変換する | [Base64 エンコーダー / デコーダー](../functional/base64.md) |
| 文字列と URL エンコードを相互に変換する | [URL エンコーダー / デコーダー](../functional/url-encoder.md) |
| 文字列のハッシュ値を作る | [ハッシュ生成ツール](../functional/hash-generator.md) |
| Unix タイムスタンプと日時を相互に変換する | [タイムスタンプ変換ツール](../functional/timestamp-converter.md) |

## 結果

- 変換した結果が、クリップボードにある。入力はサーバーへ送られていない ([プライバシー](../non-functional/privacy.md))

## 例外

- 入力が正しくないときは、その旨が示される ([共通の操作](../functional/common-actions.md))

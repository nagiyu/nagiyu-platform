# プライバシー

利用者が入力したデータの扱い。全ツールの入力と出力が対象。

## 要求水準

- 入力は、ブラウザの中で処理し、サーバーへ送らない。乗り換え変換、JSON 整形、Base64、URL、ハッシュ、タイムスタンプの各ツールが対象
- 例外として、VAPID キーの鍵は、サーバー (`/api/vapid`) で作る ([VAPID キー API](../../specs/api/vapid.md))。このとき利用者の入力はなく、サーバーは鍵を保存せず、ログにも出さない
- サーバーに保存するユーザーデータはない。ブラウザの `localStorage` に残すのは、乗り換え変換ツールの表示設定と、初回訪問ダイアログを見せたかどうかだけ ([乗り換え変換ツール](../functional/transit-converter.md)、[初回訪問ダイアログ](../functional/migration-dialog.md))
- 個人情報を取り扱わない。ログインを置かない理由は[目的](../purpose.md)に従う

## やらないこと

なし

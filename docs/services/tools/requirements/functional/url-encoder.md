# URL エンコード

文字列を URL エンコード (パーセントエンコード) し、URL エンコードされた文字列を元に戻す。ユースケースは[データを整形・変換してコピーする](../use-cases/convert-and-copy.md)。

## 要件

- エンコードとデコードを、モードで切り替えられる
- 文字列を、貼り付けと、クリップボードからの読み取りの両方で入力できる
- 結果を画面に表示し、コピーできる ([共通の操作](common-actions.md))
- デコードで、エンコードの形式として正しくない入力のときは、その旨を示す
- 変換はブラウザの中で終わる ([プライバシー](../non-functional/privacy.md))
- 今の挙動は[URL エンコーダー / デコーダー](../../specs/screen/url-encoder.md)にある

## やらないこと

なし

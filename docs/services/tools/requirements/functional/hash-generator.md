# ハッシュ生成

文字列から、SHA-256 か SHA-512 のハッシュ値を作る。出力は 16 進数 (Hex)。ユースケースは[データを整形・変換してコピーする](../use-cases/convert-and-copy.md)。

## 要件

- アルゴリズムを、SHA-256 と SHA-512 から選べる
- 文字列を、貼り付けと、クリップボードからの読み取りの両方で入力できる
- ハッシュ値を画面に表示し、コピーできる ([共通の操作](common-actions.md))
- 計算はブラウザの中で終わる ([プライバシー](../non-functional/privacy.md))
- 今の挙動は[ハッシュ生成ツール](../../specs/screen/hash-generator.md)にある

## やらないこと

なし

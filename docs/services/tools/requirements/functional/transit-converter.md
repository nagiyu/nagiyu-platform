# 乗り換え変換

乗り換え案内のテキストを、必要な項目だけに整えて、メモやチャットに貼りやすい形にする。ユースケースは[乗り換え案内を整形して送る](../use-cases/transit-to-text.md)。

## 要件

- 乗り換え案内のテキストを、貼り付けと、クリップボードからの読み取りの両方で入力できる
- 解析した結果を、読みやすい形で出力欄に表示し、コピーできる ([共通の操作](common-actions.md))
- 出力に含める項目を、利用者が選べる。選んだ設定は、次に開いたときも保たれる
- 他のアプリの共有シートから共有された内容を、入力欄に入れた状態で開ける。入れるだけで、変換は利用者が押す
- 乗り換え案内の形式でないテキストのときは、解析できない旨を示す
- 変換はブラウザの中で終わる ([プライバシー](../non-functional/privacy.md))
- 今の挙動は[乗り換え変換ツール](../../specs/screen/transit-converter.md)と[共有シートからの取り込み](../../specs/flow/share-target.md)にある

## やらないこと

- **乗り換え案内サービスからの取得 (スクレイピング)**: 利用者がコピーしたテキストを解析するだけにする。解析は、乗り換え案内サービスの書式に依存し、書式が変わると読めなくなる

# JSON 整形

JSON の文字列を、読みやすく整形するか、1 行に圧縮する。ユースケースは[データを整形・変換してコピーする](../use-cases/convert-and-copy.md)。

## 要件

- JSON の文字列を、貼り付けと、クリップボードからの読み取りの両方で入力できる
- 整形と圧縮ができる。整形のインデントは 2 スペースに固定する
- 結果を画面に表示し、コピーできる ([共通の操作](common-actions.md))
- JSON として正しくない入力のときは、その旨を示す
- 変換は、ボタンを押したときだけ行う
- 変換はブラウザの中で終わる ([プライバシー](../non-functional/privacy.md))
- 今の挙動は[JSON 整形ツール](../../specs/screen/json-formatter.md)にある

## やらないこと

なし

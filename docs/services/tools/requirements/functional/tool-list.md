# ツール一覧

使えるツールをカードで並べ、利用者が選んだツールの画面へ移れるようにする。ユースケースは[使えるツールを探す](../use-cases/find-tool.md)。

## 要件

- ツールの一覧を、カードで見られる。各カードに、ツールの名前、説明、カテゴリがある ([ツール一覧画面](../../specs/screen/home.md))
- カードを選ぶと、そのツールの画面へ移れる
- 画面の幅に応じて、カードの列数が変わる
- 全画面に共通のヘッダーとフッターがある。中身は共通ライブラリが持つ

## やらないこと

なし

# 初回訪問ダイアログ

初めて訪れた利用者に、旧バージョンからの移行を案内する。

旧バージョンの Tools を、同じドメインで運用していた。新バージョンはマニフェストや仕様が変わっているため、旧バージョンをインストール済みの利用者に、再インストールを促す必要がある。

## 要件

- 初めて訪れたとき、どの画面を開いても、案内のダイアログを出せる
- 利用者が「閉じる」を押すまで、ダイアログを閉じない。背景を押しても閉じない
- 利用者が「今後表示しない」を選んで閉じたとき、以後の訪問では出さない
- `localStorage` が使えない環境でも、エラーにならない
- 今の挙動は[初回訪問ダイアログ](../../specs/term/migration-dialog.md)にある

## やらないこと

なし

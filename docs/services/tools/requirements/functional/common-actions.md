# 共通の操作

全ツールで、画面の並びと、クリップボードの読み書き、結果の知らせ方を揃える。

## 要件

- 各ツールの画面は、入力、操作、出力の順に、縦に並べる
- 入力は、クリップボードから読み取れる。読み取った文字列は、入力欄を置き換える。タイムスタンプ変換と VAPID キー生成には、読み取りがない
- 出力は、クリップボードへ書ける
- 操作の結果 (成功と失敗) を、通知バーで知らせる
- 今の挙動は[クリップボード操作](../../specs/term/clipboard-actions.md)と[通知バー](../../specs/term/snackbar.md)にある

## やらないこと

なし

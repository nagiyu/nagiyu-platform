# Base64

テキストを Base64 にエンコードし、Base64 の文字列をテキストにデコードする。ユースケースは[データを整形・変換してコピーする](../use-cases/convert-and-copy.md)。

## 要件

- エンコードとデコードを、モードで切り替えられる
- 文字列を、貼り付けと、クリップボードからの読み取りの両方で入力できる
- 結果を画面に表示し、コピーできる ([共通の操作](common-actions.md))
- デコードで、Base64 として正しくない入力のときは、その旨を示す
- 変換はブラウザの中で終わる ([プライバシー](../non-functional/privacy.md))
- 今の挙動は[Base64 エンコーダー / デコーダー](../../specs/screen/base64.md)にある

## やらないこと

なし

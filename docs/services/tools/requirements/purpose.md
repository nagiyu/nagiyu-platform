# Tools

日常で使う小さなツール (JSON 整形、エンコード、乗り換え案内の整形など) を 1 か所に集め、ブラウザの中で完結させて、誰でもログインなしで無料で使えるようにするサービス。

## 解決したい課題

日常の作業で使う小さなツール (JSON 整形、エンコード / デコード、乗り換え案内の整形など) は世の中に多数あるが、ツールごとに別々の場所にあり、まとめて使える場所が無い。

このサービスは、自分が最もよく使うツールから順に 1 か所へ集める。変換は端末の中で終わらせ、ログインは求めない。使い方を迷わないよう、全ツールの画面と操作を揃える ([共通の操作](functional/common-actions.md))。

## 置くツール

ブラウザの中で完結する、日常の作業で使う小さなツールを置く。各ツールは独立したページにし、必要になったものから足す。次のカテゴリを、足すツールの目安にする。

| カテゴリ | 例 |
|---|---|
| データ変換 | JSON、XML、YAML 等のデータフォーマット変換 |
| エンコーディング | Base64、URL、Unicode 等のエンコード / デコード |
| セキュリティ | ハッシュ生成、JWT、暗号化 / 復号化 |
| ユーティリティ | UUID 生成、タイムスタンプ変換、乗り換え案内変換等の汎用ツール |
| デザイン | カラーコード変換、画像処理等 |

新しいツールを足すときは、そのツールの機能要件と画面の仕様を作り、[ツール一覧](functional/tool-list.md)にも足す。

## 扱わない範囲

- **ログイン**: 誰でもすぐ使えることが目的なので、利用者を識別しない。ログインを前提とする機能は置かない
- **ユーザーデータのサーバー保存**: 入力を預からないので、個人情報を扱わない。ツールの入力と出力は、ブラウザの中だけにある ([プライバシー](non-functional/privacy.md))
- **多言語**: 日本語だけで提供する

## 利用者

- **本人**: 最も重要な利用者。日常の作業で使い、新しいツールの要件を決める
- **一般の利用者**: インターネット経由でアクセスする不特定の人。開発者かどうかを問わない。ログインなしで使える。フィードバックは受け付けるが、個別の要望には必ずしも応えない

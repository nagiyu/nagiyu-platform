# プライバシー

運営者の個人情報の扱い。対象は、ログインせずに見られるページと、決済の事業者が送るメール。

## 要求水準

- ログインせずに見られるページから、運営者の本名・住所・電話番号にたどり着けない。特定商取引法に基づく表記では、これらを「請求があれば遅滞なく開示いたします」とする ([特定商取引法画面](../../specs/screen/tokushoho.md))

## やらないこと

- **Stripe が送る領収書メールから、事業者名とサポート用の住所を外すこと**: 外せないので、払った本人にだけ見える範囲として許容する。詳しい理由は[法務の文書](../../../../platform/specs/lib/ui/legal.md)の理由にある

# 課金の一貫性

Stripe の状態と、Auth が持つ課金の権利を、障害や通知の失敗があっても、最終的に一致させる水準。

## 要求水準

- Stripe に障害があっても、すでに付いている課金の権利と、それに基づく有料ロールは影響を受けない
- 通知の処理が失敗したときは、失敗を返して Stripe に再送させ、最終的に反映される ([課金の反映](../functional/billing-sync.md))
- 反映の遅れを許容する。Stripe 由来の権利の期限は、契約の請求期間の終わり + 3 日で、更新の通知が届くたびに更新する ([課金の権利](../../specs/term/role-grant.md))。期限切れや解約が有効なロールに反映されるのは、Auth がセッションを読むときで、読み直しは前回から 5 分を過ぎたとき。Auth 以外のサービスへは、利用者が Auth を通るまで届かず、最長でセッションの期限まで遅れる ([セッションのロール](../../specs/term/session-roles.md))

## やらないこと

- **期限切れ・解約の即時の反映**: 理由は[課金の反映](../functional/billing-sync.md)の「やらないこと」と同じ

# サインアウト

いずれかのサービスから、全サービスのログインを終えられるようにする。ユースケースは[サインアウトする](../use-cases/sign-out.md)。

## 要件

- いずれかのサービス (Auth 自身を含む) のヘッダーから、Auth のサインアウト確認画面を経てサインアウトでき、始めたサービスへ戻れる ([サインアウト確認画面](../../specs/screen/signout.md))
- 確認画面でキャンセルすると、サインアウトせずに元のサービスへ戻れる
- 戻り先が nagiyu のサービスの URL でないときは、その URL へは戻さず、Auth へ戻す ([戻り先](../../specs/term/callback-url.md))
- サインアウトは、ログインの状態を発行する Auth に集める。各サービスは、自前でサインアウトを受け付けず、Auth のサインアウトへ遷移させる
- 確認画面を開いただけでは、サインアウトしない。利用者がボタンを押したときだけサインアウトする。画面を開くだけでサインアウトする形だと、リンクや埋め込まれた画像から、利用者を勝手にサインアウトさせられるため

## やらないこと

なし

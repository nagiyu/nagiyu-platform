# ユーザー管理

管理者が、ユーザーの一覧を見て、手動ロールを割り当て、ユーザーを削除できるようにする。ユースケースは[ユーザーの一覧を見る](../use-cases/browse-users.md)と[ユーザーに手動ロールを割り当てる](../use-cases/assign-roles.md)。

## 要件

- `users:read` 権限を持つ管理者が、ユーザーの一覧を見られる ([ユーザー一覧画面](../../specs/screen/users.md))。ロールは ID ではなく名前で示す。管理者が ID を読んでも意味を取りにくいため
- `roles:assign` 権限を持つ管理者が、ユーザーの手動ロールを割り当てられる。割り当ては Admin サービスではなく、Auth のユーザー編集画面で行う ([ユーザー編集画面](../../specs/screen/user-edit.md))
- 権限がないときは、URL を変えずに権限なしの画面を出す
- 対象のユーザーがいないときと、それ以外の取得の失敗は、表示を分ける。再試行で直るかどうかが違うため
- `users:write` 権限を持つ管理者が、ユーザーの名前を更新できる (API のみ。画面はない)。ログインのたびに Google の名前で上書きされるため、次のログインで元に戻る ([ユーザー API](../../specs/api/users.md))
- `users:write` 権限を持つ管理者が、ユーザーを削除できる。削除は API だけで、画面はない。自分自身は削除できない。削除は Stripe の契約に触れない ([ユーザー API](../../specs/api/users.md))
- 新しく作られたユーザーは、手動ロールを持たない

## やらないこと

なし

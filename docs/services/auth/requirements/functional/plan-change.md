# 段の切り替え

契約中の利用者が、同じサービスの別の段に変えられるようにする。ユースケースは[契約の段を切り替える](../use-cases/change-tier.md)と[下げの予約を取り消す](../use-cases/cancel-downgrade.md)。

## 要件

- 上げは、Stripe の Customer Portal の確認画面で日割りの金額を確認して確定できる。すぐ上の段が有効になり、差額が日割りで即時に請求される。行き先は Auth が決める ([プラン画面](../../specs/screen/plans.md)、[課金 API](../../specs/api/billing.md))
- 下げは、Auth の画面で、切り替わる日と返金がないことを確認して確定できる。請求期間の終わりに下の段へ切り替わる予約ができ、それまでは今の段のまま使える。下げは Portal ではなく Auth が予約する。理由は[課金 API](../../specs/api/billing.md)の理由にある
- 確認画面で中止したときは、何も変わらずプランの画面へ戻る
- 下げの予約を、Auth から取り消せる。取り消すと、契約は今の段のまま残る。予約が付いている間は、Customer Portal で変更も解約もできないため、解約や別の変更をしたいときは、先に取り消す
- 解約予約中、または下げの予約中は、段の切り替えを出さない。画面に予約を示す
- 支払いを確認できていない契約 (past_due) では、切り替えを断る。理由は[課金 API](../../specs/api/billing.md)の理由にある
- 支払いの失敗や 3D セキュアは、Stripe の確認画面が扱う

## やらないこと

- **下げでの返金や日割りのクレジット**: 下げは請求期間の終わりに切り替わるため、今の期間は今の段のまま使える。返金の仕組みは持たない ([申し込みと管理](subscription.md))

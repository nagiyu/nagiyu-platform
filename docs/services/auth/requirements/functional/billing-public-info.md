# 料金と特定商取引法に基づく表記の公開

誰でも、ログインせずに、料金と特定商取引法に基づく表記を確認できるようにする。ユースケースは[料金と特定商取引法に基づく表記を見る](../use-cases/view-pricing.md)。

## 要件

- プランの内容・価格・支払いと解約の条件を、ログインせずに確認できる ([プラン画面](../../specs/screen/plans.md))
- 価格と商品の説明は、開くたびに Stripe から読む。文言を Stripe の 1 か所で管理し、価格の表記が 2 か所になって食い違うことを防ぐ
- 特定商取引法に基づく表記を、ログインせずに確認できる ([特定商取引法画面](../../specs/screen/tokushoho.md))
- 課金が有効になっていない間も、特定商取引法に基づく表記は表示する。決済事業者の審査が、表記の URL を確かめるため
- 運営者の本名・住所・電話番号は、公開ページに載せない ([プライバシー](../non-functional/privacy.md))

## やらないこと

なし

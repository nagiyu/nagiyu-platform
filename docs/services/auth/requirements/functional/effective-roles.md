# 有効なロール

手動ロールと課金の権利から利用者の有効なロールを決め、各サービスが権限だけで判定できるようにする。

## 要件

- 利用者の有効なロールは、手動ロールと、期限内で取り消されていない課金の権利のロールを合わせたものになる ([課金の権利](../../specs/term/role-grant.md))
- 有効なロールは、ログインの状態 (セッション) に載る。ログインのときと、ロールの再取得のときに届く ([セッションのロール](../../specs/term/session-roles.md))
- 課金の権利の期限は、有効なロールを決めるときに判定する
- 各サービスは、有料かどうかを、既存の権限の判定だけで決める。課金のための専用の判定を、サービスに持たせない
- ロールと権限の定義は、コードで持つ ([ロールと権限](../../../../platform/specs/lib/common/roles-and-permissions.md))

## やらないこと

- **有効なロールの変更を、各サービスへ即時に届けること**: 理由は[目的](../purpose.md)の「扱わない範囲」を参照

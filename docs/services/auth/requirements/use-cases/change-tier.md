# 契約の段を切り替える

契約中のエンドユーザーが、同じサービスの別の段に変える。

## 前提

- ログインしている
- 切り替えるサービスに、有効な契約がある

## 流れ

1. 利用者が、プランの画面で切り替える段を選ぶ ([プラン画面](../../specs/screen/plans.md))
2. 上げのとき、Stripe の Customer Portal の確認画面で日割りの金額を確認して確定する。すぐ上の段が有効になり、差額が日割りで即時に請求される
3. 下げのとき、Auth の画面で切り替わる日を確認して確定する。請求期間の終わりに下の段へ切り替わる予約ができる ([課金 API](../../specs/api/billing.md))

## 結果

- 上げでは、すぐ上の段の有料ロールが有効になる
- 下げでは、切り替わる日までは今の段のまま使え、日が来ると下の段になる。返金はない

## 例外

- 確認画面で中止したときは、何も変わらずプランの画面へ戻る
- 解約予約中、または下げの予約中は、切り替えを出さない
- 支払いを確認できていない契約 (past_due) では、切り替えを断る
- 支払いの失敗や 3D セキュアは、Stripe の確認画面が扱う

# 有料ロールを手動で付ける

管理者が、Stripe 以外で受けた支援 (pixiv FANBOX など) に対し、期限つきで有料ロールを付ける。

## 前提

- ログインしている
- `roles:assign` 権限を持っている ([ロールと権限](../../../../platform/specs/lib/common/roles-and-permissions.md))

## 流れ

1. 管理者が、対象のユーザーの編集画面を開く ([ユーザー編集画面](../../specs/screen/user-edit.md))
2. 管理者が、付ける有料ロールと有効期限を指定して、課金の権利を足す。必要なら、手動で付けた権利の期限を変える、または取り消す
3. 管理者が保存する。手動ロールの変更と一緒にまとめて保存される ([ユーザー API](../../specs/api/users.md))

## 結果

- ユーザーに、期限つきの有料ロールが付く。期限を過ぎた権利は、管理者が何もしなくても無効になる ([課金の権利](../../specs/term/role-grant.md))

## 例外

- 権限がないときは、URL を変えずに権限なしの画面を出す
- 新しい期限が現在より前のときは、エラーにする
- 取り消した権利は、変更できない
- Stripe 由来の権利は、表示だけで変更できない
- 他の更新と競合したときは、再読み込みを促す

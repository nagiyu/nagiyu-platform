# サインアウトする

エンドユーザーが、いずれかのサービスからサインアウトし、全サービスのログインを終える。

## 前提

- ログインしている

## 流れ

1. 利用者が、いずれかのサービス (Auth 自身を含む) のヘッダーからサインアウトを選ぶ
2. Auth のサインアウト確認画面が開き、利用者がサインアウトを確定する ([サインアウト確認画面](../../specs/screen/signout.md))
3. ログインの状態が消え、サインアウトを始めたサービスへ戻る

## 結果

- 全サービスでログインしていない状態になる

## 例外

- 確認画面でキャンセルしたときは、サインアウトせずに元のサービスへ戻る
- 戻り先が nagiyu のサービスでないときは、その URL へは戻さず、Auth へ戻す ([戻り先](../../specs/term/callback-url.md))

# ユーザーに手動ロールを割り当てる

管理者が、ユーザーの手動ロールを変更する。

## 前提

- ログインしている
- `roles:assign` 権限を持っている ([ロールと権限](../../../../platform/specs/lib/common/roles-and-permissions.md))

## 流れ

1. 管理者が、ユーザー一覧から対象のユーザーの編集画面を開く ([ユーザー編集画面](../../specs/screen/user-edit.md))
2. 管理者が、付けるロールを選び直して保存する ([ユーザー API](../../specs/api/users.md))
3. サービスが、ユーザーの手動ロールを保存する

## 結果

- ユーザーの手動ロールが更新される。ユーザーの有効なロールへの反映は、次のロールの再取得のときになる ([セッションのロール](../../specs/term/session-roles.md))

## 例外

- 権限がないときは、URL を変えずに権限なしの画面を出す
- 対象のユーザーがいないときは、「ユーザーが見つかりません」を出す
- 他の更新と競合したときは、再読み込みを促す

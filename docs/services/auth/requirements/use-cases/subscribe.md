# 有料プランに申し込む

エンドユーザーが、自分で有料プランに申し込み、有料ロールを得る。

## 前提

- ログインしている
- 申し込むサービスに、有効な契約がない (同じサービスの別の段の契約も含む)

## 流れ

1. 利用者が、プランの画面で段を選んで申し込む ([プラン画面](../../specs/screen/plans.md))
2. Stripe の決済画面 (Checkout) へ進み、支払いの情報を入力して支払う ([課金 API](../../specs/api/billing.md))
3. 支払いを終えて戻ると、サービスが Stripe から契約を取り直して課金の権利に反映し、ロールを再取得して、元のサービスへ戻る ([契約がロールになる経路](../../specs/flow/billing-entitlement.md))

## 結果

- 元のサービスへ戻った時点で、有料ロールが有効になっている

## 例外

- 決済画面で中止したときは、何も変わらずプランの画面へ戻る
- 未ログインのときは、ログインへ案内する
- 同じサービスの有効な契約があるときは、新たに申し込ませず、プランの画面の段の切り替えへ案内する ([段を切り替える](change-tier.md))
- 課金が有効になっていないときは、価格と操作の代わりに「準備中」を示す
- 本番以外では、`billing-tester` ロールを持たない利用者は申し込めない。画面は導線を出さずにその旨を示す

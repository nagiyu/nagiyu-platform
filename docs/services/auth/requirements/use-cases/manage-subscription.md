# 契約を管理する

契約中のエンドユーザーが、解約・支払い方法の変更・請求の確認を、自分で行う。

## 前提

- ログインしている
- Stripe の顧客と対応している

## 流れ

1. 利用者が、プランの画面で「契約を管理」を選ぶ ([プラン画面](../../specs/screen/plans.md))
2. Stripe の Customer Portal が開き、利用者が解約・支払い方法の変更・請求の確認を行う ([課金 API](../../specs/api/billing.md))
3. 利用者が、プランの画面へ戻る

## 結果

- 解約した場合も、支払い済みの期間の終わりまでは、有料ロールが有効なまま残る

## 例外

- Stripe の顧客と対応していない利用者には、「契約を管理」を出さない
- 下げの予約が付いている間は、Customer Portal で変更も解約もできない。そのときは、先に[予約を取り消す](cancel-downgrade.md)

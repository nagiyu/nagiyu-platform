# Google アカウントでログインする

エンドユーザーが Google アカウントでログインし、一度のログインで全サービスを使えるようにする。

## 前提

- Google アカウントを持っている

## 流れ

1. 利用者が、ログインが要る画面を開く。未ログインなので、Auth のサインイン画面へ送られ、ログイン後の戻り先が引き継がれる ([サインイン画面](../../specs/screen/signin.md))
2. 利用者が、Google でサインインする
3. サービスが、Google の認証のあとにユーザーを作る (すでにいれば更新する)。手動ロールと、有効な課金の権利のロールを合わせて、ログインの状態に載せる ([サインインの経路](../../specs/flow/sign-in.md))
4. 利用者が、元の画面へ戻る
5. 別のサービスを開くと、再度ログインせずに使える

## 結果

- ログインの状態が全サービスで共有され、各サービスは利用者のロールから権限を判定できる

## 例外

- Google の認証やユーザーの作成に失敗したときは、エラーを示す ([認証エラー画面](../../specs/screen/auth-error.md))
- すでにログインしている利用者がサインイン画面を開いたときは、ボタンを出さずに戻り先へ移す

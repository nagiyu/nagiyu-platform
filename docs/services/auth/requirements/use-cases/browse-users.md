# ユーザーの一覧を見る

管理者が、プラットフォームに登録されているユーザーの一覧を見る。

## 前提

- ログインしている
- `users:read` 権限を持っている ([ロールと権限](../../../../platform/specs/lib/common/roles-and-permissions.md))

## 流れ

1. 管理者が、ユーザー一覧の画面を開く ([ユーザー一覧画面](../../specs/screen/users.md))
2. サービスが、ユーザーを一覧で示す ([ユーザー API](../../specs/api/users.md))

## 結果

- 管理者が、登録されているユーザーと、それぞれのロールを確かめられる

## 例外

- 権限がないときは、URL を変えずに権限なしの画面を出す

# 料金と特定商取引法に基づく表記を見る

誰でも、ログインせずに、料金と特定商取引法に基づく表記を確認する。

## 前提

なし

## 流れ

1. 利用者が、プランの画面を開く ([プラン画面](../../specs/screen/plans.md))
2. プランの内容・価格・支払いと解約の条件を確かめる
3. 利用者が、特定商取引法に基づく表記を開く ([特定商取引法画面](../../specs/screen/tokushoho.md))

## 結果

- 利用者が、申し込む前に、料金と表記を確かめられる

## 例外

- 課金が有効になっていない間は、価格の代わりに「準備中」を示す。特定商取引法に基づく表記は、そのときも表示する

# 資源の割り当て

変換に使う資源 (vCPU とメモリ) の選び方と、同時に動かす量の抑え方。

## 要求水準

- 資源は、軽い処理には小さく、重い処理には大きく割り当てる。軽い処理に大きな資源を割り当てると費用が無駄になり、重い処理に小さな資源を割り当てると処理時間が延びるため
- 資源は、ファイルサイズと出力コーデックで選ぶ。選び方と値は[ジョブ定義のサイズ](../../specs/term/job-definition-size.md)にある
- 資源を選べないとき、または選んだ資源で投入できないときは、既定の大きさで変換を続ける。選び損ねたことで、ジョブを失敗させないため
- 同時に動かす量は、ジョブの数ではなく、資源 (vCPU) の上限で抑える。超えた分は、待たせる。上限は、小さな資源のジョブを複数、大きな資源のジョブを少数、同時に動かせる大きさにする ([変換バッチ用の実行環境](../../specs/resource/batch-runtime.md))

## やらないこと

なし

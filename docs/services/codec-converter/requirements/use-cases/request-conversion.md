# 動画の変換を依頼する

利用者が、変換したい MP4 の動画と出力コーデックを選び、変換を依頼する。

## 前提

- 変換したい MP4 の動画を手元に持っている
- 登録もログインも要らない ([匿名での利用](../functional/anonymous-access.md))

## 流れ

1. 利用者が、サービスの画面を開く ([アップロード画面](../../specs/screen/upload.md))
2. 利用者が、動画を選ぶ
3. サービスが、動画の形式とサイズを確かめる ([アップロード](../functional/upload.md))
4. 利用者が、出力コーデックを選び、変換を依頼する
5. サービスが、動画を受け取ってジョブを作る。利用者に、そのジョブの状態を確かめる画面を示す ([ジョブ詳細画面](../../specs/screen/job-detail.md))

## 結果

- ジョブができ、変換が始まる。利用者は、ジョブの ID を持つ画面から、結果を確かめられる ([変換の結果を受け取る](receive-result.md))

## 例外

- 動画の形式かサイズが条件に合わないときは、理由が示され、アップロードされない

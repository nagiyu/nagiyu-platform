# 変換の結果を受け取る

利用者が、依頼したジョブの状態を確かめ、完了していれば変換後の動画をダウンロードし、失敗していれば理由を知る。

## 前提

- 変換を依頼している ([動画の変換を依頼する](request-conversion.md))
- そのジョブの ID を知っている ([匿名での利用](../functional/anonymous-access.md))

## 流れ

1. 利用者が、ジョブ詳細画面を開く ([ジョブ詳細画面](../../specs/screen/job-detail.md))
2. 利用者が、状態を確かめる操作をする ([ジョブの状態](../functional/job-status.md))
3. 完了していれば、利用者が変換後の動画をダウンロードする ([ダウンロード](../functional/download.md))
4. 失敗していれば、サービスが失敗したことと理由を示す

## 結果

- 完了なら、利用者は変換後の動画を手に入れる
- 失敗なら、利用者は失敗した理由を知る

## 例外

- 変換が終わっていないときは、まだ終わっていない状態が示される。利用者は、あとでもう一度確かめる
- 作成から 24 時間を過ぎたジョブは消えていて、見つからない旨が示される ([データの保持](../non-functional/data-retention.md))

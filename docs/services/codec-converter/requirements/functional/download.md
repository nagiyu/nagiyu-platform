# ダウンロード

利用者が、変換後の動画をダウンロードできるようにする。ユースケースは[変換の結果を受け取る](../use-cases/receive-result.md)。

## 要件

- 署名付き URL でダウンロードする
- 署名付き URL は、24 時間有効にする
- ダウンロードの回数は制限しない。有効な間は何度でもできる
- ダウンロードできるのは、完了したジョブだけにする

画面は[ジョブ詳細画面](../../specs/screen/job-detail.md)、API は[ジョブ API](../../specs/api/jobs.md)にある。

## やらないこと

なし

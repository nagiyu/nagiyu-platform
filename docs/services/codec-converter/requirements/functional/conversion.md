# 変換

アップロードされた動画を、利用者が選んだ出力コーデックに変換する。ユースケースは[動画の変換を依頼する](../use-cases/request-conversion.md)。

## 要件

- 出力コーデックは、H.264 (MP4)、VP9 (WebM)、AV1 (WebM) から選べる ([出力コーデック](../../specs/term/output-codec.md))
- 音声は、出力のコンテナに合わせて再エンコードする
- 解像度、ビットレート、フレームレートは、元の動画を保つ
- エンコードは 1-pass で行う。処理時間を優先するため
- 変換は、2 時間で打ち切り、そのジョブは失敗にする
- 失敗した変換は、AWS Batch が再試行する (計 2 回試行する)。再試行しても失敗したら、ジョブを失敗にする
- 失敗したときに利用者へ見せるのは、失敗した段 (取得・変換・保存・それ以外) ごとの決まった文言だけにする。技術的な詳細は利用者に見せず、管理者向けにログと Admin のエラー報告に残す ([エラー報告の経路](../../specs/flow/error-reporting.md))
- 変換の途中のファイルは S3 に置かない。S3 に置くのは元の動画と変換後の動画だけにする。失敗したジョブのファイルも、ほかと同じく作成から 24 時間で消す ([データの保持](../non-functional/data-retention.md))

処理の手順は[変換バッチ](../../specs/batch/convert.md)、全体の流れは[変換の経路](../../specs/flow/conversion.md)にある。使う資源の選び方は[資源の割り当て](../non-functional/resource-allocation.md)にある。

## やらないこと

なし

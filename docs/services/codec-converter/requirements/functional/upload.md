# アップロード

利用者が、変換したい動画をブラウザからアップロードできるようにする。ユースケースは[動画の変換を依頼する](../use-cases/request-conversion.md)。

## 要件

- MP4 の動画を、500MB 以下までアップロードできる
- 形式とサイズは、ブラウザとサーバーの両方で検証する
- 動画は、Lambda を通さず、ブラウザから S3 へ直接送る
- 検証に外れたときは、理由を示してアップロードを中止する

画面は[アップロード画面](../../specs/screen/upload.md)、API は[ジョブ API](../../specs/api/jobs.md)にある。

## やらないこと

- **中断したアップロードの再開**: 利用者が、もう一度アップロードし直す

# サービス名のデプロイ先

必須。サービスがどこにどう載るかを 1〜2 文で書く。見出しは付けない。デプロイ先は各サービスと shared に 1 本置く。書くことが少ないリソース (ECR など) は文書を作らず、「スタック」の表に載せる。

> この雛形は `docs/services/<service>/specs/deploy.md` に写して使う。説明の文を消し、本文に置き換える。

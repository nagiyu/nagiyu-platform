# 機能の名前

必須。この機能で利用者が何をできるようにするかを 1〜2 文で書く。見出しは付けない。機能要件は機能 1 つにつき 1 本置く。要件は出典を持たない (`sources: []`)。

> この雛形は `docs/services/<service>/requirements/functional/<name>.md` に写して使う。説明の文を消し、本文に置き換える。

## 要件

必須。「〜できる」の形で、満たすべきことを箇条書きにする。画面の中身・API・データの形は書かず、仕様にリンクする。

## やらないこと

必須。この機能でやらないと決めたことを、理由を添えて書く。

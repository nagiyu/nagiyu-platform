# ドメインモデル

必須。このサービスが扱う概念の全体像を 1〜2 文で書く。見出しは付けない。ドメインモデルはサービスに 1 本置く。書くのは概念の名前と関係だけで、属性・キー・テーブルは仕様 (`specs/data/`) に書く。要件は出典を持たない (`sources: []`)。

> この雛形は `docs/services/<service>/requirements/domain-model.md` に写して使う。説明の文を消し、本文に置き換える。

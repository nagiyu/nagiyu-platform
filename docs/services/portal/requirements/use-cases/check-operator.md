# 運営者と運営方針を確かめる

読者や AdSense の審査担当者が、誰が・どのような方針で記事を書いているかを確かめ、必要なら問い合わせる。

## 前提

- なし。ログインは要らない

## 流れ

1. 利用者が、About を開く ([About 画面](../../specs/screen/about.md))
2. 利用者が、運営者のプロフィール、運営方針、編集ポリシーを読む
3. 記事の誤りや内容への質問があれば、お問い合わせを開き、問い合わせる ([お問い合わせ画面](../../specs/screen/contact.md))

## 結果

- 利用者は、運営者の素性と方針を確かめられる。記事へのフィードバックを送る手段もわかる

## 例外

- なし

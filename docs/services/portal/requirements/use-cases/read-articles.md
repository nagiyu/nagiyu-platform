# 技術記事を読む

読者 (エンジニア) が、AWS・Next.js などの実運用の知見を解説した記事を読む。

## 前提

- なし。ログインは要らず、全ページを公開している

## 流れ

1. 読者が、トップページまたは技術記事一覧を開く ([ホーム画面](../../specs/screen/home.md)、[技術記事一覧画面](../../specs/screen/tech.md))
2. 読者が、読みたい記事を選ぶ
3. 読者が、記事を読む ([記事詳細画面](../../specs/screen/tech-article.md))
4. 読者が、末尾の関連記事から、続けて別の記事へ進める

## 結果

- 読者は、1 本の記事の内容を読み終え、関連する記事へ進める

## 例外

- 存在しない記事の URL を開いたときは、見つからない旨の画面になる ([404 画面](../../specs/screen/not-found.md))

# 広告

Google AdSense の広告スクリプトを、本番の環境にだけ読み込む。

## 要件

- AdSense のスクリプトは、本番 (prod) の環境でビルドしたときだけ読み込む。dev など、本番を複製した環境には出さない ([ホーム画面](../../specs/screen/home.md)の「全画面で共通の部分」)
- 環境が明示されていないときも、読み込まない。広告の出し漏れより、複製環境への出力のほうが、審査上の害が大きいため
- AdSense の `ads.txt` を、ドメインの直下 (`/ads.txt`) で配信する

## やらないこと

なし

# 運営者の情報

運営者と運営方針、問い合わせ手段、利用規約、プライバシーポリシーを、誰でも確かめられるように公開する。技術メディアとしての信頼 (E-E-A-T) を示すためである ([目的](../purpose.md))。ユースケースは[運営者と運営方針を確かめる](../use-cases/check-operator.md)。

## 要件

- 運営者のプロフィール、運営方針、編集ポリシーを公開する ([About 画面](../../specs/screen/about.md))
- 記事の誤りの指摘や内容への質問を、問い合わせフォームで受け付ける ([お問い合わせ画面](../../specs/screen/contact.md))
- 利用規約とプライバシーポリシーを公開する ([利用規約・プライバシーポリシー画面](../../specs/screen/legal.md))
- いずれもログインなしで読める

## やらないこと

なし

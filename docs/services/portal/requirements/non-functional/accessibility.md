# アクセシビリティ

読者が、端末や支援技術によらず記事を読めるための水準。対象は Portal の全ページ。UI 部品の水準は[UI コンポーネントの規約](../../../../platform/rules/ui-components.md)に従い、ここには Portal のページとしての水準だけを書く。

## 要求水準

- Lighthouse の Accessibility が 90 以上
- WCAG 2.1 AA を目標にする
- 画像に代替テキスト (alt) を付ける
- モバイルで読める
    - タップできる領域は 48px 四方以上
    - 本文の文字は 14px 以上
    - ズームしなくても、全コンテンツを読める
    - 横スクロールが出ない。表やコードは、その中で横にスクロールする

## やらないこと

なし

# セキュリティ

ニコニコのセッション情報の保護の水準。セッション情報は、アカウントを操作できる資格情報である。

## 要求水準

- セッション情報は、暗号化して利用者ごとに保存する ([ニコニコセッション](../../specs/term/user-session.md))
- 本人だけが読める
- 生の値を、ログ・レスポンス・クライアントに出さない

## やらないこと

- **上の水準を超える保護**: 本人専用の利用を前提にしているため ([目的](../purpose.md))
- **失効の体験の改善** (期限前の予告通知、保存した情報の一括失効など): 失効は、利用時の判定とバッチ実行直前の再判定で確実に検知できるため

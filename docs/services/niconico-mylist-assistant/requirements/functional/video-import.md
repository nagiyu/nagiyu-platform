# 動画の取り込み

利用者が、ニコニコ動画の動画を、検索または動画 ID の一覧から取り込めるようにする。ユースケースは[検索して動画を取り込む](../use-cases/import-by-search.md)と[動画 ID を並べて取り込む](../use-cases/import-by-ids.md)。

## 要件

- キーワードで検索し、結果から選んで取り込める。画面は[動画取り込み画面](../../specs/screen/import.md)、API は[動画取り込み API](../../specs/api/video-import.md)
- 動画 ID の一覧から、動画の基本情報をまとめて取得して保存できる
- 検索結果は、利用者が操作する前の時点で、既登録かどうかを表示する
- 既登録の判定は、動画の基本情報があるかどうかで行う。利用者の設定は関与させない。動画の基本情報は全利用者で共通で、取り込み済みかどうかはその有無だけで決まるため ([動画の基本情報](../../specs/term/video-basic-info.md))

## やらないこと

なし。

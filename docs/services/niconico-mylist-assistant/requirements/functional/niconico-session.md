# ニコニコのセッション

ニコニコを操作する機能が、利用者がブラウザで取得したセッションを使って動くようにする。ユースケースは[ニコニコのセッションを登録する](../use-cases/register-session.md)。

## 要件

- 利用者がブラウザでログインして得たセッションを、登録・更新できる ([ニコニコセッション API](../../specs/api/niconico-session.md)、[ニコニコセッション](../../specs/term/user-session.md))
- ニコニコを操作する前に、セッションが有効かどうかを判定する
- 無効なときは、登録・更新を促して、操作を止める
- 一時的な不調で有効かどうかを判定できないときは、利用者を締め出さない
- セッションの保護は[セキュリティ](../non-functional/security.md)に従う

## やらないこと

- **ニコニコへのログインの自動化**: 理由は[目的](../purpose.md)の「扱わない範囲」と同じ
- **パスワードを扱う・保存すること**: ログインを自動化しない以上、必要がなく、持たないほうが漏れる危険がない

# 動画の設定を編集する

利用者が、取り込み済みの動画に、お気に入り・スキップ・メモを付けたり直したりする。マイリストへ登録する動画の選び方に使う。

## 前提

- 動画が取り込まれている

## 流れ

1. 利用者が [動画管理画面](../../specs/screen/videos.md) で、動画を一覧から探す
2. 利用者が、お気に入り・スキップ・メモを編集する ([動画 API](../../specs/api/videos.md))
3. サービスが、利用者の設定として保存する ([動画の設定](../../specs/term/video-setting.md))

## 結果

- 設定が保存され、以後のマイリスト登録の選び方に反映される

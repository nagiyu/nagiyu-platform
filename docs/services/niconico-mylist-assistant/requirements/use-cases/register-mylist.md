# マイリストへ一括登録する

利用者が、条件で選んだ動画から最大 100 件をランダムに選び、ニコニコのマイリストへまとめて登録する。

## 前提

- 動画が取り込まれている ([検索で取り込む](import-by-search.md)、[ID で取り込む](import-by-ids.md))
- 有効なニコニコのセッションが登録されている ([セッションを登録する](register-session.md))

## 流れ

1. 利用者が [マイリスト登録画面](../../specs/screen/mylist-register.md) で、条件 (お気に入りのみ、スキップを除くなど) を指定して依頼する
2. サービスが条件に合う動画から最大 100 件をランダムに選び、登録ジョブを作る ([マイリスト登録 API](../../specs/api/mylist-register.md))
3. 既存のマイリストの動画を消してから、選んだ動画を登録する ([マイリスト登録バッチ](../../specs/batch/mylist-register.md))
4. 利用者が、画面で進み具合と結果を確かめる ([ジョブ状況画面](../../specs/screen/job-status.md))。完了は通知でも届く

流れ全体は[マイリスト登録の経路](../../specs/flow/mylist-registration.md)にある。

## 結果

- ニコニコのマイリストに、選ばれた動画が登録されている
- 成功した件数と失敗した件数を、利用者が確かめられる

## 例外

- ニコニコのセッションが無効なとき、依頼は止まり、登録・更新を促される
- 一部の動画の登録に失敗しても、残りの動画の登録は続ける。失敗した件数は結果に出る

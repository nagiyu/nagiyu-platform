# 動画 ID を並べて取り込む

利用者が、動画 ID の一覧から、動画の基本情報をまとめて取得して保存する。

## 前提

- 取り込みたい動画の ID が手元にある ([動画 ID](../../specs/term/video-id.md))
- 有効なニコニコのセッションが登録されている ([セッションを登録する](register-session.md))

## 流れ

1. 利用者が [動画取り込み画面](../../specs/screen/import.md) に、動画 ID の一覧を入れる
2. サービスが各動画の基本情報をニコニコから取得して保存する ([動画取り込み API](../../specs/api/video-import.md))
3. 利用者が、取り込めた動画と取り込めなかった動画を確かめる

## 結果

- 取得できた動画の基本情報が保存され、動画の一覧に出る

## 例外

- ニコニコのセッションが無効なとき、取り込みは止まり、登録・更新を促される
- 取得できなかった動画は、取り込まれない

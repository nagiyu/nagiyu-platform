# ニコニコのセッションを登録する

利用者が、ブラウザでニコニコにログインして得たセッションを、サービスに登録または更新する。ニコニコを操作する機能は、このセッションを使う。

## 前提

- 利用者が、ブラウザでニコニコにログインしている

## 流れ

1. 利用者が、ブラウザのログインで得たセッション (`user_session`) の値を取り出す
2. 利用者が、サービスの画面からセッションを登録または更新する ([ニコニコセッション API](../../specs/api/niconico-session.md)、[ホーム画面](../../specs/screen/home.md))
3. サービスがセッションを暗号化して保存し、有効かどうかを判定する

流れ全体は[セッションの登録から利用まで](../../specs/flow/session-injection.md)にある。

## 結果

- ニコニコのセッションが保存され、ニコニコを操作する機能が使える

## 例外

- セッションが無効だと判定されたとき、登録・更新を促され、ニコニコを操作する機能は使えない
- 失効する (ニコニコ側でログアウトされる、期限が切れる) と、再び登録・更新が要る

# 検索して動画を取り込む

利用者が、キーワードでニコニコ動画を検索し、結果から選んで動画を取り込む。

## 前提

- このサービスにログインしている

## 流れ

1. 利用者が [動画取り込み画面](../../specs/screen/import.md) で、キーワードを入れて検索する
2. サービスが検索結果を返す。各動画が、すでに取り込み済みかどうかも示される ([動画取り込み API](../../specs/api/video-import.md))
3. 利用者が、取り込む動画を結果から選ぶ
4. サービスが選ばれた動画の基本情報を保存する

## 結果

- 選んだ動画の基本情報が保存され、動画の一覧に出る

# niconico-mylist-assistant

ニコニコ動画で大量の動画をマイリストに登録する手作業を減らす、本人専用の補助ツール。

## 解決したい課題

マイリストへ動画を 1 件ずつ登録する作業は手間がかかり、登録する動画を選ぶ手間も大きい。このサービスは、取り込んだ動画の中から条件に合うものを選び、マイリストへまとめて登録する。作業の効率と登録の精度を上げることが目的である。

## 扱わない範囲

- **複数の利用者での運用**: 本人専用の利用を前提にしている。たとえば動画を削除すると、他の利用者がその動画に持つ設定が残る ([動画の設定](../specs/data/main-table.md))。利用者が今 1 人なので、対処しない。セキュリティも、暗号化と本人だけが読めることに留める ([セキュリティ](non-functional/security.md))
- **ニコニコへのログインの自動化**: ログイン画面に bot 対策 (人間判定) があり、自動入力のログインは常に失敗する。判定を機械的に突破する手段は不安定で、非公式な自動アクセスを禁じる規約に抵触するおそれがあるため、行わない。利用者がブラウザでログインして得たセッションを使う ([ニコニコのセッション](functional/niconico-session.md))

# プライバシーポリシー

Quick Clip のプライバシーポリシー。共通の文面に、Quick Clip だけの変更を 2 つ加えたもの。フッターのプライバシーポリシーのダイアログに出る。

## 説明

共通の文面 ([法務の文書](../../../../platform/specs/lib/ui/legal.md)の `privacyPolicySections`) を土台にし、次の 2 点だけを変える。ほかの節は、共通の文面のまま。

| 変更 | 節の見出し | 位置 | 中身の要点 |
|---|---|---|---|
| 足す | さくっとクリップの利用回数の制限について | 「Cookieの設定について」の直後 | 利用回数の制限で、Cookie と IP アドレスを使うこと (下に詳細) |
| 差し替える | データの取り扱い | 共通の文面と同じ位置 | 動画をサーバーで処理し、AI 解析では OpenAI に送ること (下に詳細) |

### 足す節: 利用回数の制限について

- 無料でご利用いただける回数を管理するため、ログインしていない方のブラウザに、当サービスが発行するランダムな識別子を Cookie として保存する。この識別子は、利用回数を数えるためだけに使い、氏名などの個人を特定する情報とは結び付けない
- 同じ接続元からの過度な利用を防ぐため、アクセス元の IP アドレスを利用する。IP アドレスはそのままでは保存せず、日ごとに変わる値と組み合わせて変換したうえで記録し、数日以内に自動で削除する
- ログインしている方の利用回数は、アカウントごとに記録する
- Cookie を受け付けない設定の場合も、IP アドレスによる上限の範囲で利用できる

数え方の実際は[利用回数の流れ](../flow/usage-metering.md)にある。

### 差し替える節: データの取り扱い

共通の文面は、「ツールはすべてお使いのブラウザ内でのみ処理され、入力されたデータは、サーバーや外部のサーバーに送信されることはない」と述べる。Quick Clip では、次の内容に差し替える。

- 見どころを抽出するため、アップロードされた動画を、当サイトのサーバー (Amazon Web Services) で処理する
- アップロードされた動画と処理の結果は、作成から 24 時間で利用できなくなり、その後、自動的に削除する
- AI 解析を行う場合は、文字起こしと感情分析のため、動画の音声と文字起こしの結果を OpenAI の API に送信する ([AI 解析](./ai-analysis.md))

### 組み立て方

共通の文面の節の見出し (「Cookieの設定について」「データの取り扱い」) を手がかりに、差し替えと挿入の位置を決める。共通の文面からどちらかの見出しがなくなると、変更が効かなくなる。

## 理由

- **「データの取り扱い」を差し替える**: 共通の文面は、すべてブラウザ内で処理され、サーバーに送らないと述べる。動画をサーバーで処理し、AI 解析で OpenAI に送る Quick Clip の実態と合わない
- **利用回数の制限の節を足す**: 未ログインの回数を数えるために、Cookie と IP アドレスを使う。この説明は、Quick Clip だけの仕組みなので、共通の文面には載せず、このサービスだけに足す

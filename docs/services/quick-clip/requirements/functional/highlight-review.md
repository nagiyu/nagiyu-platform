# 見どころの確認と調整

抽出された見どころを、利用者がブラウザ上でプレビューし、採否の判定と時間の調整ができるようにする。ユースケースは[見どころを確かめて選ぶ](../use-cases/review-highlights.md)。

## 要件

- 抽出された見どころを、開始時刻の順に一覧できる。抽出の根拠は、必要なときだけ列として出せる。列の表示と非表示は、利用者が切り替えられる ([見どころ確認画面](../../specs/screen/highlights.md))
- 見どころを選んで、切り出し済みのクリップをブラウザ上でプレビューできる。画面を開いた時点で、全クリップが再生できる。最初のクリップは、抽出の中で生成する ([抽出バッチ](../../specs/batch/extract.md))
- 見どころに、未確認、使える、使えないの 3 つの採否を付けられる。初期値は未確認 ([見どころとクリップの状態](../../specs/term/highlight.md))
- 見どころの開始と終了の時刻を調整できる。調整すると、クリップが自動で作り直され、確認済みの採否は未確認に戻る。作り直しが終わるまでは、その見どころの時刻を変更できない ([見どころ API](../../specs/api/highlights.md)、[クリップ再生成](../../specs/batch/clip-regenerate.md))
- クリップの生成に失敗したときは、その見どころのクリップをやり直せる
- クリップの生成が終わっていない間は、生成の進捗を示す
- 選んだ見どころの区間に重なる文字起こしを表示する。文字起こしがなければ表示しない ([文字起こし](../../specs/term/transcript.md))
- 一部の見どころだけを採用した状態でも、ダウンロードに進める

## やらないこと

なし

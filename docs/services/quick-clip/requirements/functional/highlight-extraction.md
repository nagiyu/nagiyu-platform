# 見どころの抽出

アップロードされた動画から、見どころの区間を自動で抽出する。ユースケースは[動画をアップロードする](../use-cases/upload-video.md)。

## 要件

- 映像の変化量と音量から、見どころの区間を最大 20 件抽出する。区間は重ならない。同じ時間帯が複数の根拠で検出されたときは 1 件にまとめる ([抽出バッチ](../../specs/batch/extract.md))
- 抽出した見どころは、どの根拠 (映像の変化、音量、感情、複数) で選んだかを持つ ([見どころとクリップの状態](../../specs/term/highlight.md))
- [AI 解析](../../specs/term/ai-analysis.md)をするジョブでは、文字起こしと感情分析から感情スコアを算出し、映像の変化と音量に並ぶ第 3 の根拠として使う
- AI 解析ができないとき (文字起こしが空、API の失敗など) は、その処理を飛ばし、映像の変化と音量だけで抽出を続ける。ジョブ全体は失敗にしない
- 感情フィルタ (`laugh`、`excite`、`touch`、`tension`、`any`) を、ジョブ作成の API で指定できる。指定した感情を重視して見どころを抽出する。画面からは指定しない ([ジョブ API](../../specs/api/jobs.md))

## やらないこと

なし

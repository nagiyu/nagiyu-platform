# 処理の進み具合

処理中のジョブの進み具合を、利用者が確かめられるようにする。ユースケースは[動画をアップロードする](../use-cases/upload-video.md)。

## 要件

- 利用者が、ジョブのステータス (処理待ち、処理中、処理完了、処理失敗) を処理状況の画面で確かめられる。ジョブ ID を知っていれば、ログインしなくても開ける ([処理状況画面](../../specs/screen/job-status.md))
- 処理状況の画面に、アップロード、解析、切り出しの段階を示し、処理中の段階を常に分かるようにする
- 解析の段階では、モーション分析、音量分析、文字起こし、感情分析のそれぞれの進捗を示す。AI 解析をしないジョブでは、文字起こしと感情分析を示さない ([AI 解析](../../specs/term/ai-analysis.md))
- 処理中の画面に、タブを閉じても処理が続くことを示す。URL を控えれば、後から確かめられる
- 処理状況の画面と見どころの確認画面に、データの有効期限を示す ([データの保持](../non-functional/data-retention.md))
- 処理に失敗したときは、その内容を示し、再アップロードに進める

## やらないこと

なし

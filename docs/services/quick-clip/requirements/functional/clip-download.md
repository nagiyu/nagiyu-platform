# クリップのダウンロード

採用した見どころのクリップを、利用者が ZIP でまとめてダウンロードできるようにする。ユースケースは[クリップをまとめて受け取る](../use-cases/download-clips.md)。

## 要件

- 採用した見どころのクリップを、ZIP でダウンロードできる ([ダウンロード API](../../specs/api/download.md)、[ZIP 生成](../../specs/batch/zip-generate.md))
- 採用したクリップの生成がすべて終わるまで、ダウンロードできない。理由を画面に示す ([見どころ確認画面](../../specs/screen/highlights.md))
- ZIP の中のファイル名は、見どころの番号と連動する
- 文字起こしがあるクリップには、対応するテキストを、同名で同じ ZIP に入れる ([文字起こし](../../specs/term/transcript.md))

## やらないこと

なし

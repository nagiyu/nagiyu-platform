# さくっとクリップ (QuickClip)

動画投稿者が、長い動画から見どころの候補を自動で抽出し、確かめて選んだ区間を分割クリップとして書き出すためのサービス。英語名は QuickClip。

## 解決したい課題

長時間の動画から見どころを探す作業は、手間がかかり時間を要する。このサービスは、動画の変化量と音量を客観的な指標として見どころを機械的に抽出し、この作業を自動化する。文字起こしと感情分析 ([AI 解析](../specs/term/ai-analysis.md)) による意味的な見どころも、映像と音量の抽出に加える。

利用者は、動画をアップロードするだけで見どころの候補を得る。候補をブラウザ上でプレビューしながら採否の判定と時間の調整をし、採用した見どころを分割クリップの ZIP としてダウンロードする。

ログインしなくても使える。ログインや有料プラン (スタンダードとプロの 2 段) で、使える量が増える ([利用回数の制限](functional/usage-limits.md))。有料プランの段と申し込みは Auth が持つ ([プランの段](../../auth/specs/term/plan-tier.md)、[申し込みと管理](../../auth/requirements/functional/subscription.md))。

## 扱わない範囲

- **可用性の目標**: 稼働率・RTO・RPO の目標は設定せず、ベストエフォートで提供する。AWS サービスの可用性に依存するため

## 利用者

- **動画投稿者**: YouTuber やニコニコ動画の投稿者など。長時間の動画から、切り抜きやハイライト動画の素材を作りたい人

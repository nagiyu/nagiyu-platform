# 動画をアップロードする

動画投稿者が、長い動画をアップロードし、見どころの抽出を始める。

## 前提

- ログインは要らない。ログインの有無と有料プランの段で、使える量が変わる ([利用回数の制限](../functional/usage-limits.md))

## 流れ

1. 利用者が、アップロード画面で動画ファイルを選ぶ ([アップロード画面](../../specs/screen/upload.md))
2. サービスが、ファイルの形式とサイズ、動画の長さを確かめる
3. 利用者が、AI 解析をするかしないかを選ぶ。残りの回数が画面に出る
4. 利用者が、処理の開始を指示する。サービスが利用回数を数え、動画をアップロードする。進捗が画面に出る
5. アップロードが終わると、処理状況の画面へ進む。ここから、見どころの抽出が進む ([処理の進み具合](../functional/job-progress.md))

## 結果

- 動画のジョブができ、見どころの抽出が始まっている
- 利用者は、処理状況の画面の URL を控えれば、タブを閉じても後から状況を確かめられる

## 例外

- 非対応の形式の動画、上限を超えるサイズの動画は、アップロードを始めずに断る
- 動画の長さが段の上限を超えるときは、アップロードを始めずに断る。ログインしていない利用者にはログインを、ログイン中の利用者にはプランの画面を案内する。一番上の段 (プロ、使い放題) の利用者には、プランの画面を案内しない
- 選んだ種類 (AI 解析あり、なし) の今月の回数の上限に達しているときは、アップロードを始めずに断る。ログインしていない利用者にはログインを、ログイン中の利用者にはプランの画面を案内する。一番上の段の利用者には、プランの画面を案内しない
- 未ログインの利用者が、同じ接続元からの 1 日の上限に達しているときは、アップロードを始めずに断る。案内は出さない
- アップロードに失敗したときは、その旨を示す。数えた利用回数は戻る。ただし、分割アップロードの途中でタブを閉じるなど、失敗がサービスに伝わらないときは戻らない ([利用回数の制限](../functional/usage-limits.md))
- 抽出の処理が失敗したときも、数えた利用回数は戻る。ただし、処理がプロセスごと止まる失敗 (Batch のタイムアウトなど) では戻らない

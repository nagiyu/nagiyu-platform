# クリップをまとめて受け取る

動画投稿者が、採用した見どころのクリップを ZIP でまとめてダウンロードする。

## 前提

- 見どころを確かめ終えている ([見どころを確かめて選ぶ](review-highlights.md))
- 1 件以上の見どころを採用している

## 流れ

1. 利用者が、見どころの確認画面で ZIP のダウンロードを指示する ([見どころ確認画面](../../specs/screen/highlights.md))
2. サービスが、採用した見どころのクリップをまとめて ZIP を作る。文字起こしのあるクリップには、対応するテキストを同じ ZIP に入れる
3. ZIP ができると、サービスがダウンロードできるようにする

## 結果

- 利用者の端末に、採用した見どころのクリップを入れた ZIP が保存されている

## 例外

- 採用した見どころのクリップの生成がすべて終わるまで、ダウンロードできない。生成に失敗したクリップが採用されているときは、リトライするか採用を外すように示す
- 採用した見どころがないときは、ダウンロードできない
- ZIP の生成に失敗したとき、または待っても ZIP ができないときは、一定の時間で待つのをやめ、ダウンロードの開始に失敗した旨を示す。利用者は、もう一度ダウンロードを指示できる ([見どころ確認画面](../../specs/screen/highlights.md))

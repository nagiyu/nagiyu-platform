# 見どころを確かめて選ぶ

動画投稿者が、抽出された見どころをプレビューし、採否を決め、必要なら開始と終了を調整する。

## 前提

- 動画のジョブの処理が完了している ([動画をアップロードする](upload-video.md))
- ログインは要らない。ジョブ ID を知っていれば開ける

## 流れ

1. 利用者が、処理状況の画面から見どころの確認画面へ進む ([見どころ確認画面](../../specs/screen/highlights.md))
2. サービスが、見どころを番号の順に一覧する。番号は、抽出のときの開始時刻の順に付いている。どのクリップも、画面を開いた時点で再生できる
3. 利用者が、見どころを選んでクリップをプレビューする
4. 利用者が、見どころを使える、使えない、未確認のどれかにする
5. 必要なら、利用者が見どころの開始と終了の時刻を調整する。サービスが、そのクリップを自動で作り直す。調整した見どころの採否は、未確認に戻る
6. 利用者が、採用した見どころでダウンロードへ進む ([クリップをまとめて受け取る](download-clips.md))

## 結果

- 利用者が、どの見どころを採用するかを決め終えている

## 例外

- ジョブの処理が終わっていないとき、失敗したときは、見どころを出さず、処理状況の画面への案内を出す
- クリップの作り直しに失敗したときは、その見どころで作り直しをやり直せる
- 見どころが 1 件もないときは、その旨を示す

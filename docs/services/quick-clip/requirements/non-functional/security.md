# セキュリティ

利用者の動画とクリップを守る水準。Cookie の属性や XSS などの共通の水準は[セキュリティ](../../../../platform/rules/security.md)に従う。

## 要求水準

- すべての通信は HTTPS で行う
- 保存したデータは、S3 の SSE-S3 (サーバー側の暗号化) で暗号化する ([S3 バケット](../../specs/resource/storage.md)、[サービスの S3 バケット](../../../../platform/specs/resource/service-bucket.md))
- S3 のバケットは非公開にする。動画、クリップ、ZIP へのアクセスは、署名つきの URL だけで許す
- ジョブへのアクセスは、ジョブ ID だけで制御する。ジョブ ID を知っていれば誰でも処理の状況と見どころを確認できるため、ジョブ ID は推測できない値 (UUID v4) にして、リスクを軽減する ([ジョブとステータス](../../specs/term/job.md))

## やらないこと

なし

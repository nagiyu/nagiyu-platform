# S3

S3 へのアップロード、署名付き URL の発行、オブジェクトの URL の組み立て。`@nagiyu/aws` から import する。

## 使い方

| 関数 | 引数 | 戻り値 |
|---|---|---|
| `createS3Client` | `config.region` (省略可) | 新しい S3 クライアント (キャッシュしない) |
| `getS3Client` | `region` (省略可) | リージョンごとにキャッシュした S3 クライアント ([AWS クライアント](./clients.md)) |
| `uploadFile` | `client`、`options` | ETag (`string` か `undefined`) |
| `createPresignedUploadUrl` | `options`、`client` (省略可) | アップロード (PUT) 用の署名付き URL |
| `createPresignedDownloadUrl` | `options`、`client` (省略可) | ダウンロード (GET) 用の署名付き URL |
| `getS3ObjectUrl` | `bucketName`、`key`、`region` (省略可) | オブジェクトの URL |

| `options` の項目 | 対象 | 内容 |
|---|---|---|
| `bucketName`、`key` | `uploadFile`、`createPresignedUploadUrl`、`createPresignedDownloadUrl` | 対象のオブジェクト。`getS3ObjectUrl` は `options` ではなく位置引数で受け取る |
| `body` | `uploadFile` | `Buffer`、`Uint8Array`、`string` |
| `contentType` | `uploadFile`、`createPresignedUploadUrl` | 省略可 |
| `metadata` | `uploadFile` | `Record<string, string>`。省略可 |
| `expiresIn` | 署名付き URL | 有効期限 (秒)。必須 |

```ts
const url = await createPresignedDownloadUrl({ bucketName, key, expiresIn: 300 });
```

## 振る舞い

| 項目 | 内容 |
|---|---|
| 署名付き URL のクライアント | `client` を省略すると、`getS3Client()` のキャッシュ済みクライアントを使う |
| `createS3Client` のリージョン | 引数、環境変数 `AWS_REGION`、`us-east-1` の順で決める |
| `uploadFile` | `PutObject` を 1 回送る。失敗は包まずそのまま投げる |
| `getS3ObjectUrl` のリージョン | 既定は `us-east-1`。環境変数 `AWS_REGION` は見ない |
| `getS3ObjectUrl` の形式 | `https://{bucketName}.s3.{region}.amazonaws.com/{key}`。`key` はエンコードしない |

`getS3ObjectUrl` は文字列を組み立てるだけで、オブジェクトを読めるかは確かめない。

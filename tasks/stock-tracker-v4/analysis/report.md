# Stock Tracker v4 確度算出方式の比較（ウォークフォワード）

再現: `python3 prep.py && python3 run.py && python3 analyze.py && python3 neutral.py`（同ディレクトリ。詳細表は `out/tables.md`・`out/neutral.md`、図は `out/calib_Q-*.png`、全結果は `out/results.csv`）。乱数はブートストラップのみ（seed=0）。

## 1. 結論と推奨

**選定ルール（結果を見る前に固定）**: 主指標 = OOS log loss の M0 比改善 ΔLL（正で改善）。採用候補は「全体で日付ブロック・ブートストラップ 90% CI が 0 を跨がない」かつ「前半・後半の両方で改善」。僅差なら単純で内訳を説明しやすい方式を優先。試した設定の総数は **95 通り**（方式ハイパラ 12 × 問い 3、窓・更新・N・軸セットの変種）。「OOS で一番よかった設定」をそのまま採ると過大評価になるため、以下は家族単位で見ている。

| 問い | 結果の要約 | 推奨 |
|---|---|---|
| **Q-DIR 方向** | **どの方式も M0 を改善しない**（ΔLL −0.0007〜0.0000、CI はすべて 0 を跨ぐ、AUC 0.49〜0.50）。確率の 96% が基準 ±5pt 以内に留まる。全軸投入はむしろ悪化（有意）。 | 方式の差が出ないので、**Q-VOL と同じ方式（B）を強めの縮小（α=80 相当）で共用**し、表示はほぼ「中立」になることを前提にする。OOS では buy_ge2 点灯 56 件の的中 73%（+1.41pt）が再現したが、学習期間（3〜7 月）では 48% で効かなかったため重みが付かなかった（局面依存の実例）。 |
| **Q-VOL 大きさ** | **全方式が有意に改善**。B（L2 ロジスティック）ΔLL +0.045 [+0.036, +0.054]、BSS +0.089、AUC 0.666。A（縮小付き加算）+0.038、D +0.042、C（B+指数減衰）+0.048〜0.051。前半・後半・JP・US すべてで改善。 | **B（L2 正則化ロジスティック回帰、拡張窓・日次更新）**。軸は大きさ 3 軸 + 市場平均の大きさ 3 軸（ΔLL +0.053、ECE 0.046 に改善）。**指数減衰の重み（C, 半減期 40 日）は同じ実装にサンプル重みを足すだけ**で、キャリブレーションを改善する（ECE 0.062→0.052）ため、オプションとして持つ価値あり。 |
| **Q-MKT 市場の荒れ** | ΔLL は大きい（B +0.16）が **n=92、実現率 24%（前半 42%・後半 2%）で、ECE 0.17 と確率としては信用できない**。改善の中身は「夏場の凪で低い確率を出し続けたら当たった」に近い。 | 方式は Q-VOL と同じ B を共用しつつ、**確率の表示は当面「参考値」扱い**（中立帯を広く取る、または基準値と一緒に件数を出す）。単純ルール「当日の市場平均値幅 > 平常なら翌日も荒れる」でも OOS で 64% vs 11% の分離が出ており、軸 1 本で足りる可能性がある。 |

方式の長所短所（人が最終判断するための比較）:

| 方式 | 長所 | 短所 | 本データでの成績 |
|---|---|---|---|
| M0 基準値のみ | 最も単純・崩れない | 情報ゼロ | Q-VOL/Q-MKT で基準値そのものが局面でずれる（後述） |
| A 縮小付き対数オッズ加算 | 軸ごとの「点灯時的中率 vs 基準」をそのまま表示に使える（FR-16 と一対一）。実装は集計だけ | 相関を無視するため、相関の強い軸を足すと過信する（Q-VOL に市場軸を足すと ΔLL +0.038→+0.003 に**悪化**、Q-DIR 全軸で有意に悪化） | Q-VOL +0.038（B より −0.007）。κ は 20〜200 で差は小さく、大きいほど安全 |
| **B L2 ロジスティック** | 相関を同時推定で吸収（FR-10c）。軸を足しても壊れにくい（Q-VOL: 市場軸追加で改善、パターン追加でも不変）。寄与 = 係数 × 値 で内訳表示可。正則化が FR-10b の「件数不足→ゼロ寄り」を自然に実現 | 係数が「点灯時的中率」と直結しないため説明に一段の変換が要る。標準化の平均・分散を保存する必要 | Q-VOL +0.045、α=5/20/80 の差はほぼ無し（α で安定）。B-cv（窓内 CV で α 選択）は同等で、コストに見合わない |
| C = B + 指数減衰重み | 基準値の局面ずれに追従（FR-10d）。B と同じコード | 半減期が短いほど OOS 良好だが（h=20 が最良）、学習サンプルが減るぶん過学習リスク。h の選択根拠が薄い | Q-VOL +0.048（h=40）〜+0.051（h=20）。ECE 0.044〜0.052 |
| D 相関クラスタ＋縮小加算 | A の説明しやすさを保ちつつ相関を扱う | クラスタ化の閾値 ρ で結果が振れる（Q-VOL ρ=0.3: +0.037、ρ=0.5: +0.042）。クラスタが日々変わると内訳表示が不安定 | B に届かない。Q-MKT ではクラスタ化で情報が潰れて A/B の半分 |

**設計上の推奨（追加分析より）**: 平常の N は **20** を推奨（§4）。中立帯は **前半 OOS の帯ごとの有意差**で決める方式 (i) が要件どおりだが、**基準値（M0）自体が局面でずれる**ため、帯は「確率 − 基準値」の差で持ち、基準値は直近窓（60 日）または減衰付きで更新することを推奨（§5）。FR-5 は **対応固定**（パターン系→Q-DIR、大きさ系→Q-VOL・Q-MKT、ただし Q-VOL には市場平均の大きさ軸も入れる）を推奨（§6）。

## 2. 設定

- データ: DailySummary 17,162 行 → 除外後 16,204 行。除外 1（休場日コピー）867 + OHLC 同一 1、除外 2（途中足）90、除外 3（|翌日リターン| > 20%）21 件をターゲットから除外。翌営業日は同一銘柄の次レコードで、市場カレンダー（平日 − 休場リスト）の翌営業日と一致するものだけをターゲットに使う（不一致 259 件を除外。8/31〜9/2 のデータ欠落と、途中足除外の前日が主）。JP は 8/28→9/3、US は 8/28→9/2 のギャップあり。
- パターンの買い/売り区分はリポジトリの `signalType` で確定: **買い 11・売り 16**（要件書の「買い 10・売り 17」と 1 つずれる。tweezer-bottom / three-gaps-hammering などが BUY）。ascending-triangle / rising-three-methods / falling-three-methods は全期間で合致 0 件。INSUFFICIENT_DATA セル 2,619（3 月上旬のみ、0 扱い）。
- ターゲット: Q-DIR = 翌日リターン − 同日・同市場（JP=TSE, US=NASDAQ+NYSE+AMEX）の有効銘柄平均 > 0。Q-VOL = (H−L)_{t+1}/C_t > 直近 N 日の値幅平均（当日込み、フル N 日必須）。Q-MKT = 翌日の市場平均値幅 > 市場平均値幅の直近 N 日平均。
- 軸: パターン 27 + buy_ge2 + sell_ge2（点灯型）。大きさ 3 軸は log(当日値 / 平常 N 日) で水準除去（Parkinson 5 日 / N 日、当日値幅 / 平均値幅、出来高 / 平均出来高）。市場平均 3 軸 + 市場値幅の水準除去版（Q-MKT）。
- 将来データ混入防止: 予測日 t（市場 m の引け時刻）で、ラベル確定時刻（翌営業日の引け、市場ごとの時刻）≤ 予測時刻のサンプルだけを学習に使う（US 引けは JP 引けより遅いので、JP 予測時に US の当日ラベルは使わない）。標準化・分位ビン・クラスタ・α 選択もすべて学習サンプル内で行う。
- バーンイン: N=60 の平常 60 営業日 + 学習の最小 30 営業日 = **90 営業日**。主評価窓 **2026-07-14〜09-25**（JP 46 / US 50 営業日、Q-DIR n=5,552、Q-VOL n=5,432、Q-MKT n=92）。前半/後半の分割日 08-19。N=20 の拡張窓（05-19〜、n≈10k）は副次的に参照。
- 方式のハイパラ: A κ∈{20,50,200}、B α∈{5,20,80}（総和損失スケールの L2、切片は非正則化。点灯型は 0/1 のまま、数値型は標準化）、B-cv（窓末尾 25% で α 選択）、C α=20 × 半減期 {20,40,80}、D ρ∈{0.3,0.5} × κ=50。窓 {拡張, 120, 60}、更新 {日次, 週次}。

## 7. 計算コストと内訳表示

- B（Newton 法・自前 numpy 実装）: 15,787 × 29 の学習が **17ms**、A は 8ms。35 軸程度なら TypeScript で正規方程式（35×35 の連立）を 10 回反復するだけで、Lambda で問題にならない。日次更新と週次更新で成績差は小さい（Q-VOL −0.002）が、コストが軽いので**日次**でよい。
- 内訳: B は「寄与 = 係数 × 標準化値」で軸ごとに分解でき、`logit(p) = 切片 + Σ 寄与` が厳密に成り立つ。A は「点灯時的中率 − 基準」の対数オッズ差の和で、FR-16 の表示（件数・的中率・基準との差）と一対一になる。B の係数を FR-16 に出す場合は、軸の成績（件数・点灯時的中率）は別途集計して並べ、寄与は係数 × 値で示す二段構えになる。
- FR-10b（件数不足→ゼロ寄り）: B では L2 が自然に効く（0/1 軸を標準化しないことが重要。標準化すると希少軸の係数が膨らむ）。「件数不足で重みがゼロ寄り」の表示は、点灯数 < 閾値（例 30）を別途判定して出すのが簡単。

## 8. 注意点

1. **データ期間が短い**。OOS は 2026-07-14〜09-25 の 46〜50 営業日、局面は実質「7 月の荒れ」「8〜9 月の凪」の 2 つだけ。Q-VOL の ΔLL の大きさ（+0.045）や Q-MKT の数字は、この 2 局面の切り替わりを含んだ値で、平時の水準はもっと小さい可能性が高い（N=20 拡張窓では +0.027）。
2. **基準値（M0）の局面ずれ**が全問いに共通する最大の問題。方式の選択より、基準値・切片の追従（直近窓 or 減衰）のほうが確率の信頼性に効く。
3. Q-DIR の buy_ge2 は OOS で 56 件・的中 73%・超過 +1.41pt [+0.65, +2.15]（日付ブートストラップ）と再現したが、学習期間では 48%（n=91）で効かず、モデルは重みを付けられなかった。全期間では 147 件・58%・+0.89pt（#3831 と一致）。「測りながら使う」設計の意義そのものだが、当面 Q-DIR は中立が大半になる。
4. ハイパラ探索は 95 設定。上表のうち「一番よい設定」（Q-VOL の C h=20、Q-MKT の A κ=20）は選択バイアスを含むため推奨にしていない。B は α でほぼ結果が変わらない点が、選択バイアスに強い理由。
5. 8/31〜9/2 のデータ欠落、3 月末の部分欠損、休場日レコード（#3833 以降は発生しない）を除外している。本番の FR-13 初期値算出でも同じ除外を入れること。
6. 3 パターン（ascending-triangle / rising-three-methods / falling-three-methods）は全期間 0 件で重みは常に 0。パターンの買い/売り区分（11/16）は要件書の記述（10/17）と異なるので確認が必要。
